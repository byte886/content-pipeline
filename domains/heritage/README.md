## 本域建包纪律

1. 每个子域独立 `knowledge_base/README.md`（来源表 + 分类 + 采集配置），不合并、不混写
2. 新子域启用顺序：先建调研技能行业包（词库+查询模板）→ 再补监控仓渠道矩阵 → 最后 pipeline 采集配置
3. 知识成品统一 OKF（type 词表见各仓 AGENTS 声明），存量不强制回填、新写自然采用
