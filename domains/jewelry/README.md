## 珠宝视频知识库构建SOP（项目级）

> 通用知识提取维度在技能里：`multiplatform-media-fetch/references/domain-plugins/jewelry.md`
> 本文件是项目级具体规则

### 一、视频分类规则（自动预判）
| 价值等级 | 标题特征 | 处理方式 |
|---|---|---|
| 高价值科普 | 什么是、区别、鉴别、A货、种水、色、产地 | 下载+转写+知识提取 |
| 潘家园实战 | 潘家园、带粉丝、挑战、捡漏、预算 | 下载+转写，作为实战案例 |
| 普通展示 | 品鉴、给大家看一个、打灯看 | 只截图，不下载 |
| 水视频 | 节日、祝福、新年快乐、中秋 | 不处理 |
| 广告活动 | 寻宝、征集、直播、抽奖 | 不处理 |

### 二、品类标签规则
按标题自动打品类标签：
- 翡翠：帝王绿、冰种、糯种、墨翠、油青、种水、A货
- 南红：南红、保山、凉山、冰飘
- 和田玉：籽料、山料、白玉、碧玉、墨玉
- 彩色宝石：红宝石、蓝宝石、祖母绿、碧玺
- 有机宝石：蜜蜡、琥珀、珍珠、猛犸象牙

### 三、知识提取维度（珠宝行业专属）
1. **核心概念**：这个视频讲了什么知识点（比如"翡翠的种是什么"）
2. **鉴别要点**：怎么辨真假、怎么看好坏、和相似品种的区别
3. **价格信息**：提到的具体价格、行情判断
4. **关键帧**：实物展示类视频必须截3-5张关键图（整体、打灯、细节）
5. **标签**：#品类 #知识点 #鉴别 方便检索

### 四、知识文档输出模板
```markdown
# [视频标题]

> 来源：抖音@[博主] | 品类：[品类] | 时长：X秒

## 核心知识点
（结构化要点）

## 鉴别要点
（怎么辨真假、怎么看好坏）

## 关键帧
（实物展示类视频放3-5张图：整体、打灯、细节）

## 标签
#翡翠 #帝王绿 #种水
```
