# ADR-006: 文稿用途分型（读者 / 知识 / 运营 / 视频创作）

> **状态**：已采纳
> **日期**：2026-10-12
> **决策者**：AI + 用户

## 背景

工作流 G0 目标形态最初只有"文稿 / 知识库 / 视频分析 / 评论研究 / 双写"。用户指出：从各类资料得到的文稿**不只一种**——专业知识文稿、运营（自媒体发布）文稿、生成视频用的文稿，需要按行业/需求生成不同类型。此前工作流把"文稿"默认当读者阅读一种用途，运营与视频创作两条产出链路未纳入目标形态。

## 决策

将"文稿"按**用途/目的地**分为四型，纳入 G0 目标形态与 G4 成文决策：

| 文稿类型 | 目的地 | 结构依据 | 落点 |
|---|---|---|---|
| 读者文稿 | 面向读者阅读 | article-pipeline §4 七类作者角色结构 | `library/06_articles/` |
| 知识文稿 | 沉淀鉴藏知识体系 | OKF KnowledgeNote（frontmatter / sources / 分级） | `library/05_knowledge/`（经 S5） |
| 运营文稿 | 自媒体发布（标题 / 文案 / 口播稿 / 平台适配） | 运营方法（郭颖研究、平台适配规则） | we-media-ops 发布侧 |
| 视频创作文稿 | 生成视频用（脚本 / 分镜 / 提示词 / 创作对标卡片） | 视频分析方法（画面层 + 音频层，video-effect-analysis） | video-studio |

判断原则：**先问"这份文稿给谁用、达成什么"**——沉淀知识 → 知识文稿；发平台引流 → 运营文稿；驱动视频生产 → 视频创作文稿；给人读 → 读者文稿。行业差异由 domain-plugin 提供内容维度与结构侧重。

### 关联执行位置

- G0 目标形态：扩充为 读者 / 知识 / 运营 / 视频创作 / 视频分析 / 评论研究 / 双写（多选）——融合规划 §4.1 G0、workflow-main §3.1；
- G4 成文决策：按型落点，支持多产物双写——融合规划 §4.1 G4、workflow-main §7.3；
- 分型详情表：workflow-main §7.1（执行层正文）；
- 结构选择（每型内部怎么写）：article-pipeline §4 七类角色结构（权威源技能目录）。

## 后果

### 正面
- 采集前（G0）就能声明产出形态，链路不默认写成一种格式；
- 知识 / 运营 / 视频三条产出链路由清晰，各自落点明确；
- 同一躯干可多产物双写，避免重复加工。

### 负面
- 目标形态字段变多，任务卡预判需更明确（G0 决策成本略升）；
- 运营文稿与视频创作文稿的"写作规范"仍分散在 we-media-ops / video-studio，未在 workflow 内统一成文（后续 P2/P3 可选补）。
