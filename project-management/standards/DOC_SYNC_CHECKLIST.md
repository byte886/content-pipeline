# 文档同步检查清单（DOC_SYNC_CHECKLIST）

> **文档类型**：Standard（规范 — 检查清单）
> **更新频率**：流程变更时
> **维护者**：AI自动维护
> **读者**：AI代理（完成阶段性任务后必须执行）

> 每次完成阶段性任务、生成新文档、或变化项目结构时，必须按本清单检查并同步相关文档。
> 设计参考高顿CPA项目DOC_SYNC_CHECKLIST.md，根据本项目特点简化。

---

## 同步时机

必须执行本检查清单的场景：
1. 完成采集批次后（短视频/直播回放/公众号文章）
2. 完成转写/OCR批次后
3. 发现问题并解决后
4. 项目结构调整后（新增/删除/移动目录或文件）
5. 大阶段完成后
6. 每次git提交前

## 快速检查命令

```bash
# 检查git状态，确认没有不该提交的文件
git status

# 检查文档中是否有失效链接（简单grep）
grep -r "TODO\|待补充\|待完善" docs/ project-management/ AGENTS.md README.md

# 检查空目录
find . -type d -empty -not -path "./.git/*"
```

## 同步原则

1. **问题驱动更新**：发现问题立即评估是否需要更新文档
2. **本地文档为主**：所有文档以本地为准，飞书等外部文档为辅
3. **不抄易变计数**：已下载多少、已转写多少以现场成品文件为准，不抄进文档
4. **稳定结论指针化**：过程件只放指针指向ADR/记忆，不复制结论正文
5. **提交前必查**：每次git提交前必须跑一遍本清单
