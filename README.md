# 股票知识库系统（Stock Knowledge Base）

> 基于「交易的游戏」视频号 + 「顶底之王」公众号内容，构建A股投资知识库，为量化系统和内容创作提供素材基础。

## 项目定位

**一句话**：自动采集、结构化、可检索的A股投资知识库，服务于量化策略研发和公众号/视频号内容创作。

**核心价值**：
- 把零散的视频/文章/书籍转化为结构化、可检索的知识
- 为量化系统提供策略灵感和验证素材
- 为内容创作提供文案模板和素材库

## 目标用户

- 主要用户：自己（单人项目）
- 用途1：量化策略研发（提取交易信号、指标用法、策略逻辑）
- 用途2：内容创作（生成公众号文章、短视频脚本、直播大纲）

## 知识库结构

```
knowledge-base/
├── 01-视频号内容/          # 口语化、实时性强
│   ├── 短视频/（按主题分类）
│   └── 直播回放/（按日期排序）
├── 02-公众号文章/          # 系统化、图文并茂
│   ├── 市场分析/
│   ├── 板块研究/
│   ├── 个股点评/
│   └── 投资理念/
├── 03-书籍精华/            # 理论基础
│   ├── 技术分析/
│   ├── 价值投资/
│   ├── 量化交易/
│   └── 投资心理/
├── 04-知识点图谱/          # 结构化提取
│   ├── 技术指标库/
│   ├── 财务指标库/
│   ├── 宏观经济/
│   └── 交易策略库/
└── 05-文案素材库/          # 生成你的内容
    ├── 短视频脚本/
    ├── 公众号文案/
    └── 直播大纲/
```

**设计原则**：分工存储，标签关联。视频号/公众号/书籍三者表达方式不同，分开存储；通过统一标签体系（如"MACD底背离"、"券商板块"）交叉关联。

## 技术栈

- **视频处理**：ffmpeg（压缩/转码）、FunASR（语音转文字）
- **微信数据**：wx-cli（本地数据库解密读取）、res-downloader（视频抓包下载）
- **UI自动化**：mac_computer_use_tool（微信/Chrome操作）
- **OCR**：macOS Vision（图片文字识别）
- **知识库**：Markdown文件 + 标签体系（后续可接入向量数据库）
- **定时任务**：cron（每日增量采集）
