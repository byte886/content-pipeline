## 0. 通用操作前置规则（所有操作前必须遵守）

### 0.0 窗口激活确认（最高优先级！）
> 执行任何键盘快捷键（Cmd+W/Cmd+F/输入文字）之前，**必须先确认当前激活的窗口是微信窗口**！
- 验证方法：看屏幕最顶部菜单栏左侧的应用名，显示"微信"才可以执行快捷键
- ❌ 没确认就按Cmd+W，会把当前激活的其他窗口（比如豆包）关掉！

### 0.1 完整UI定位步骤（强制执行，禁止跳步）
1. **全屏截图（带鼠标）**：`screencapture -x -C /tmp/step1.png`，根据屏幕上可见的文字/图标（如"搜索账号"文字、相机图标）评估目标位置
2. **粗定位悬停**：用`python3 -c "import pyautogui; pyautogui.moveTo(X,Y, duration=0.5)"`把鼠标平滑移到目标大致位置（视觉上可见移动过程）
3. **再次全屏截图（带鼠标）**：`screencapture -x -C /tmp/step2.png`，根据元素类型验证是否到位
4. **验证通过才操作**，不满足就微调位置，直到验证通过

> ❌ 强制禁止：不完成上述4步就直接点击坐标！窗口大小/位置随任务变化，旧坐标100%不准，必须每次重新截图定位。

### 0.2 不同元素的验证标准
| 元素类型 | 交互方式 | 验证标准 |
|---------|---------|---------|
| 普通可点击条目/标签（账号、分类标签、菜单选项） | 悬停即可预览效果，不需要点击 | ① 鼠标变手型 ② 整个元素变浅灰色高亮 ③ 变灰元素上的文字/图标和目标完全一致 |
| 输入框 | 必须点击聚焦后才会有交互反馈 | ① 点击后光标在输入框内 ② 输入内容后出现下拉建议列表（微信浏览器搜索框内右侧有相机图标作为定位参考） |
| 视频缩略图 | 正式采集流程中禁止点击（会打开播放页，干扰流程），仅UI测试时操作 | — |

> ❌ 禁止不截图验证就直接点击坐标！反复点错的根源就是跳过了截图验证这一步。
>
> 注意：当前选中的标签下面有黑色下划线，一直是高亮的，不是悬停变灰的！不要搞混。

## 1. 窗口管理

### 1.1 打开与激活
```bash
# 打开/恢复微信
osascript -e 'tell application "WeChat" to reopen'
sleep 0.3
osascript -e 'tell application "WeChat" to activate'
sleep 0.2
```

**激活验证（必须）**：菜单栏左上角显示"微信"，窗口红黄绿按钮是彩色。否则键盘和点击都不生效。

> ❌ 不要用鼠标点击激活窗口，容易误操作打开新页面。

### 1.2 窗口位置与大小
```bash
# 获取位置
osascript -e 'tell application "System Events" to tell process "WeChat" to get position of window 1'
# 获取大小
osascript -e 'tell application "System Events" to tell process "WeChat" to get size of window 1'
```

**调整大小/位置**：
```bash
osascript <<'OSA'
tell application "System Events"
  tell process "WeChat"
    set size of window 1 to {900, 600}
    set position of window 1 to {0, 0}
  end tell
end tell
OSA
```

> 如果osascript不生效（通讯录页面等），用鼠标拖动窗口右下角。

### 1.3 标准布局（任务开始时统一调整）

**布局原则**：按优先级从左到右排布，横向不够再往下排，窗口不重叠。

| 优先级 | 窗口 | 1920x1200参考位置 | 大小 |
|--------|------|-------------------|------|
| 1级 | 主窗口（聊天列表） | 左上角 (0,0) | 900x600 |
| 2级 | 微信浏览器/搜索结果 | 主窗口右侧 (900,0) | 1010x600 |
| 3级 | 其它（朋友圈等） | 主窗口下方 (0,600) | 900x590 |

**窗口识别（必须用标题判断，绝对不能用索引！）**：窗口索引会随着窗口开关变化，非常不可靠！
- 主窗口：标题"微信"
- 搜索/浏览器：标题含"搜一搜"或"微信 (窗口)"
- 朋友圈：标题"朋友圈"

**布局完必须验证（强制！）**：调整完窗口位置和大小后，必须截图检查：
1. 主窗口在左边，搜索窗口在右边，不重叠
2. 两个窗口都完整显示，没有被裁切
3. 确认没问题了再开始操作，不要直接开始点坐标

**触发布局调整**：任务开始时、打开新窗口后、窗口重叠遮挡时。

### 1.4 前置被盖住的窗口
```bash
osascript -e 'tell application "System Events" to tell process "WeChat" to perform action "AXRaise" of window N'
```
> N用窗口索引，但调整前先确认窗口标题。

## 2. 导航操作

### 2.1 左侧导航快捷键
| 快捷键 | 功能 |
|--------|------|
| `Cmd+1` | 聊天 |
| `Cmd+2` | 通讯录 |
| `Cmd+3` | 收藏 |
| `Cmd+4` | 朋友圈（新窗口） |
| `Cmd+5~9` | 无对应功能 |

### 2.2 退出聊天输入状态
在跟某人聊天时，Tab键作用于聊天输入框，不能切到搜索框。需要先退出。
**方法（推荐）**：点击聊天列表获取焦点 → 按↓键切换会话 → 右侧显示空白微信图标即退出。
> End键只滚动列表，不切换会话，不可靠。不要点左侧导航栏空白区域，不能退出输入状态。

### 2.3 打开朋友圈
按 `Cmd+4`，新窗口打开，放在主窗口下方。

## 3. 搜索操作

### 3.1 主窗口完整搜索流程（强制）
1. 激活主窗口（§1.1），验证菜单栏显示"微信"，切到聊天状态
2. 按 `Cmd+F` 激活搜索框（绿色边框+下拉框），或直接鼠标点顶部搜索框
3. 输入关键词：`echo -n "词" | pbcopy` + `Cmd+V`
4. **不要数按↓的次数**！本地结果（联系人/群聊/公众号/服务号）数量随聊天历史动态变化，写死次数100%点错：
   - 鼠标移到下拉列表区域
   - 用 `pyautogui.scroll(-3)` 向下滚动下拉列表，直到看到"搜索网络结果"字样
   - 直接用pyautogui点击"搜索网络结果"区块下第一个目标条目
5. 完整搜一搜结果页打开后，按§0.2三标准悬停验证条目类型（必须看下方"视频号"/"公众号"/"服务号"标签），确认后再点击进入
> ❌ 禁止用固定次数↓选条目，本地结果数量不固定，一定会误点到聊天/群聊/公众号窗口。

### 3.2 主窗口搜索框替换内容
按 `Cmd+F` 直接激活搜索框，直接输入新内容自动覆盖。不要用Cmd+A（会全选聊天列表）。

### 3.3 微信浏览器（搜一搜/视频号窗口）操作

#### 在浏览器中搜索新内容
1. 按§0.1流程定位顶部搜索框（框内有"搜索账号"提示文字，右侧有相机图标）
2. 点击聚焦后输入新内容，输入后出现下拉建议即验证成功
3. 按↓键选第一个建议，回车确认搜索

> ❌ **微信浏览器特有规则**：
> 1. `Cmd+F` 是全局网页文字查找，弹出顶部查找条；**ESC取消不了这个查找条**，必须用鼠标点查找条右上角的×才能关闭；它**不是**打开顶部搜索输入框
> 2. Tab键在微信浏览器中基本无效，不能用来切换到搜索输入框，也不能切换标签栏
> 3. `Cmd+A` 是全选整个网页，不要在浏览器中乱按，必须先点搜索框确保焦点。

#### 识别并打开视频号/公众号
1. **必须先切到"全部"标签页**（默认可能停留在"划线"等其他标签，看不到完整结果）
2. 按§0.2标准悬停验证条目：鼠标变手型、条目变浅灰、文字正确
3. 视频号条目有"视频号"字样，公众号条目有"公众号"字样
4. 验证通过后再点击

#### 关闭多余标签页
- 点标签页右侧×按钮，或按 `Cmd+W`
- 只剩最后一个标签时，`Cmd+W`会关闭整个微信浏览器窗口，不是关单个标签。

## 4. 坐标校准与工具规范

### 4.1 核心原则
1. **不要依赖经验推算坐标！** 窗口大小和位置会变，元素位置和间隔都会变。
2. **每次开始操作前，按§0.1全屏截图重新定位**，不硬套老经验。
3. **每移动一步都验证**，不对就微调。

### 4.2 坐标间隔规律
- 标签间隔随窗口宽度变化：窗口越窄间隔越小，越宽间隔越大
- 最左侧第一个特殊标签（如"AI搜索"）和后续普通标签的间隔，与普通标签之间的间隔不一致，计算间隔时要从第二个普通标签开始算

### 4.3 工具命令（默认全部用pyautogui）
```python
import pyautogui
# 平滑移动鼠标（视觉可见，用于悬停校准）
pyautogui.moveTo(x, y, duration=0.5)
# 单击
pyautogui.click(x, y)
# 滚动（pages=1对应一个屏幕高度）
pyautogui.scroll(1000)  # 正数向上滚，负数向下滚
# 读取当前鼠标位置
print(pyautogui.position())
```

**cliclick仅作为点击备用**：
```bash
cliclick c:x,y          # 单击（点击用）
cliclick p               # 读出当前鼠标位置
```
> ❌ 禁止用`cliclick m:x,y`移动鼠标：它视觉上不更新鼠标箭头，截图里看不到位置变化，无法验证悬停效果。

**截图必须加`-C`参数**：才能看到鼠标光标和形状，否则截图里看不到鼠标：
```bash
screencapture -x -C /tmp/screenshot.png  # 带鼠标光标截图
```

## 6. 常见问题
| 问题 | 解决方案 |
|------|---------|
| Tab键没反应 | 在聊天输入状态，用↓键切换会话退出（§2.2） |
| 键盘/点击没反应 | 检查窗口是否激活：菜单栏显示"微信"，按钮彩色（§1.1） |
| 点搜索建议没触发 | 单击即可，瞄准中心，不要拖拽 |
| 窗口被盖住 | AXRaise前置（§1.4） |
| Cmd+W关了整个微信 | 只有主窗口时Cmd+W关窗口，用reopen重开 |
| 中文输入失败 | 用剪贴板，osascript keystroke不支持中文 |
| Computer use截图过期 | 重试，频繁出现则换cliclick |
| 误发消息 | 确认搜索框有绿色边框再输入 |
| 搜索结果看不到视频号/公众号 | 停留在"划线"等其他标签页，必须先点"全部"标签页 |
| 悬停后标签不变灰 | 窗口没激活，先activate窗口再试 |
| 截图里看不到鼠标 | 截图命令加`-C`参数 |
| 不小心按Cmd+F弹出网页查找条 | ESC取消不了，鼠标点查找条右上角×关闭 |
| 点同名条目打开了公众号/服务号 | 必须看条目下方的类型标签：目标是视频号就找带"视频号"字样的条目，不要只看名称（三个同名条目：公众号、视频号、服务号并排显示） |
| 用cliclick m移动鼠标后截图看不到位置变化 | 换用pyautogui.moveTo()，它视觉上可见移动过程 |
| 点错标签页（划线/文章/直播）看不到完整结果 | 必须先点顶部"全部"标签，所有结果才会完整展示 |
