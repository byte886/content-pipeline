# 微信UI自动化基础SOP

> **微信版本**：4.1.8（锁定，禁止升级）
> **适用**：macOS微信所有UI自动化操作的通用基础规范；Windows将所有`Cmd`替换为`Ctrl`
> **场景SOP**：视频号采集见[wechat-channels-capture.md](wechat-channels-capture.md)，公众号采集见[wechat-official-article.md](wechat-official-article.md)

---

## 0. 工具选型（强制，禁止混用）
1.  鼠标操作（移动/悬停/点击/滚动）：统一用`pyautogui`，移动过程视觉可见可验证
2.  窗口管理/系统快捷键：统一用`osascript`
3.  坐标定位：必须用`screencapture -x -C`（带鼠标光标）全屏截图+`scripts/wechat_ocr.sh`识别元素实时坐标
4.  ❌ 禁用`cliclick`（移动鼠标视觉不更新）、禁用macOS AX辅助树操作微信自绘UI（读不到元素）、禁止写死任何固定坐标

---

## 1. 操作前准备（每次任务开始必做）
### 1.1 激活主窗口
按顺序执行：
1.  `tell application "WeChat" to reopen`还原所有最小化窗口
2.  `tell application "WeChat" to activate`把微信调到前台
3.  按1次ESC关闭当前弹出的浮层
4.  按`Cmd+1`切回聊天视图
5.  如果右侧聊天输入框处于激活状态，点击左侧聊天列表空白区域退出输入状态

### 1.2 窗口判别（100%可靠）
**禁止用窗口标题判断窗口类型**（子窗口加载前标题也显示"微信"），截图看窗口最左侧10%区域：
| 窗口类型 | 左侧特征 | 角色 |
|---|---|---|
| 主窗口 | 有一竖排圆形导航图标（聊天/通讯录/收藏/朋友圈/视频号） | 仅作为搜索入口 |
| 浏览器窗口 | 无竖排导航图标，直接显示网页内容 | 后续所有采集操作的目标窗口 |

### 1.3 窗口布局与清理
- **布局**：按优先级从左到右排布，窗口之间不重叠（1920x1200参考）：主窗口左上角`(0,0)`尺寸`900x600`；浏览器窗口主窗口右侧`(900,0)`尺寸`1010x600`；其他窗口放主窗口下方。微信沙盒限制AppleScript无法自动修改窗口位置，布局后必须截图验证实际位置再操作。
- **清理**：切换新账号/关键词时关闭所有浏览器窗口，回主窗口重新搜索，不操控浏览器自带搜索框（历史多次出错不可靠）；多窗口残留时禁止直接点击，先截图确认当前焦点窗口是目标窗口再操作。

### 1.4 核心操作铁律
1.  **每步必截图验证**：操作前截图定位目标元素→操作→操作后截图确认结果，错误立即修正，禁止不验证就继续下一步
2.  **焦点校验**：操作前截图确认当前激活的是目标窗口（主窗口/浏览器），焦点不对时所有按键失效
3.  **操作方式区分**：主窗口下拉列表优先用快捷键、键盘上下键选择，不需要鼠标悬停；浏览器窗口里的链接/标签，鼠标悬停验证（鼠标变手型/元素变灰/文字匹配）后再点击
4.  **中文输入**：必须`echo "关键词" | pbcopy`后`Cmd+V`粘贴，osascript不支持中文直接输入

## 2. 主窗口搜索流程
1.  按§1.1完成主窗口激活
2.  按`Cmd+F`激活顶部搜索框，粘贴关键词
3.  鼠标悬停在下拉列表条目文字区域（落在空白区域滚轮不响应），向下滚动列表，每滚动2-3次OCR识别一次
4.  直到OCR完全匹配红色星号前缀的"搜索网络结果"——**禁止看到"搜索"两个字就停止**，下拉列表同时存在"搜索聊天记录"入口，模糊匹配必然误进
5.  OCR识别目标条目实时坐标，主窗口优先用键盘上下键选中目标，确认条目下方类型标签（公众号/视频号/服务号）正确后按回车进入，禁止写死↓按键次数（本地结果数量动态变化）

---

## 3. 浏览器窗口通用规则
1.  进入搜一搜结果页后先切到"全部"标签，否则结果不完整
2.  点击条目必须悬停验证：鼠标变手型、条目变灰、下方类型标签与目标一致
3.  `Cmd+F`是网页全局文字查找，不是账号搜索框，弹出的查找条必须鼠标点×关闭；Tab键在浏览器内完全无效
4.  多余标签页按`Cmd+W`关闭；只剩最后一个标签时按`Cmd+W`会关闭整个浏览器窗口

---

## 4. 常见问题
| 问题 | 解决 |
|---|---|
| 快捷键无响应 | 截图确认当前激活窗口是目标窗口，焦点不对时按键不生效 |
| 滚动下拉列表不响应 | 鼠标必须落在条目文字区域，不能在左侧空白栏 |
| 点错同名条目 | 确认下方类型标签（视频号/公众号）正确再点击 |
| Cmd+W关掉整个微信 | 只剩主窗口时会触发，用`reopen`重开 |
| 误开"搜索聊天记录" | 必须OCR确认到"搜索网络结果"区段再选择条目 |
