## 一、文件命名规范

### 1.1 通用格式

```
YYYY-MM-DD_标题.md
```

**示例**：
- `2026-09-01_A股如期反弹而反弹仅仅是个开始.md`
- `2026-09-05_大盘底部特征分析.md`

**规则**：
- 日期优先，方便按时间排序
- 标题简洁，不超过30个字符
- 用中文，不用拼音
- 特殊字符用空格代替（#、/等）

### 1.2 视频号内容

**短视频**：
```
01-视频号内容/短视频/YYYY-MM-DD_标题.md
```

**直播回放**：
```
01-视频号内容/直播回放/YYYY-MM-DD_标题.md
```

### 1.3 公众号文章

按分类存放：
```
02-公众号文章/市场分析/YYYY-MM-DD_标题.md
02-公众号文章/板块研究/YYYY-MM-DD_标题.md
02-公众号文章/个股点评/YYYY-MM-DD_标题.md
02-公众号文章/投资理念/YYYY-MM-DD_标题.md
```

### 1.4 知识点

```
04-知识点图谱/技术指标库/指标名称.md
04-知识点图谱/交易策略库/策略名称.md
```

## 三、标签体系

### 3.1 一级标签（必选）

| 标签 | 说明 |
|------|------|
| 市场分析 | 大盘走势、指数分析 |
| 板块研究 | 行业板块、概念板块 |
| 个股点评 | 具体股票分析 |
| 技术分析 | 技术指标、K线形态 |
| 投资理念 | 投资哲学、心态管理 |
| 宏观经济 | 政策、利率、通胀 |
| 量化交易 | 策略、回测、因子 |

### 3.2 二级标签（可选，多选）

**技术指标类**：
- MACD、KDJ、RSI、布林带、均线、成交量、换手率、市盈率、市净率

**板块概念类**：
- 券商、科技、新能源、消费、医药、军工、半导体、AI、机器人

**市场状态类**：
- 牛市、熊市、震荡、底部、顶部、反弹、回调、突破、破位

**交易策略类**：
- 趋势跟踪、均值回归、波段操作、打板、低吸、高抛、止损、仓位管理

### 3.3 标签使用规则

- 每条内容至少2个标签，最多5个
- 一级标签必选1个，二级标签可选
- 标签用中文，不用英文缩写（除非是通用术语如MACD）
- 新增标签需要在`_tags.json`中登记

## 五、质量标准

### 5.1 转写质量

- 准确率≥90%（财经术语正确）
- 无明显错别字（"的地得"可放宽）
- 数字、股票代码必须准确
- 说话人标注（直播回放多人时）

### 5.2 文章提取质量

- 正文完整（不含广告、无关推荐）
- 图片保留（有OCR结果）
- 发布时间准确
- 作者信息完整

### 5.3 知识点质量

- 定义准确（有来源支撑）
- 有实战案例（至少1个）
- 有操作策略（可执行）
- 有相关内容链接

## 六、更新流程

### 6.1 新内容入库

1. 采集内容（视频/文章）
2. 处理内容（转写/提取/OCR）
3. AI分类打标签
4. 人工审核（抽检20%）
5. 存入对应目录
6. 更新索引文件

### 6.2 索引更新

- 每日23:00自动更新
- 新增内容后手动触发更新
- 用`scripts/knowledge/update_index.py`脚本
