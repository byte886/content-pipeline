## 四、风险与依赖

### 外部依赖
| 依赖 | 状态 | 风险 |
|------|------|------|
| 微信4.1.8版本 | 已锁定 | 自动更新可能破坏解密 |
| res-downloader运行 | 需保持开启 | 关闭后无法抓新视频 |
| Clash代理 | 需保持开启 | 国外资源下载需要 |
| FunASR模型 | 已下载 | 模型文件不可删除 |

### 技术风险
| 风险 | 应对 |
|------|------|
| 微信版本升级 | 关闭自动更新，锁定4.1.8 |
| 视频号反爬 | 多方案备份，控制频率 |
| 转写准确率低 | 人工抽检，必要时微调 |
| 磁盘空间不足 | 定期清理原始视频，保留压缩版 |
