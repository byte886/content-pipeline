## 三、待优化项 📋

### 3.1 下载质量与性能
- [ ] **高质量URL研究**：当前下载的是低分辨率版本（2-5MB/个），研究高质量URL的正确构建方式
  - 现状：原始URL返回低分辨率，只保留encfilekey+token的URL测试不工作
  - 目标：找到能下载高清版本的URL格式
- [ ] **解密速度优化**：预生成解密数组缓存
  - 现状：每个视频启动Node.js生成128KB解密数组，耗时约1-2秒/个
  - 优化：相同DecodeKey的视频复用缓存，或预生成常用Key的数组

### 3.2 采集机制
- [ ] **增量采集**：只采集新视频，不重复采集
  - 记录已采集的视频ID/URL哈希
  - 每次采集只处理新增的N条
  - 支持"跟踪模式"：定期检查新内容

### 3.3 内容处理
- [ ] **视频转文字**：使用FunASR或whisper
  - 参考已有自定义技能（FunASR）
  - 短视频：批量转写
  - 直播回放：分段转写（长视频）
  - 输出格式：带时间戳的SRT/VTT + 纯文本
- [ ] **图文OCR解析**：公众号文章中的图片
  - 参考已有自定义技能（OCR）
  - 识别文章中的图表、截图、思维导图
  - 提取图片中的文字内容补充到知识库

### 3.4 知识库建设
- [ ] **知识库生成与组织**
  - 视频转文字稿 → 结构化知识点
  - 公众号文章 → 分类整理
  - 股票知识库体系设计（技术面/基本面/资金面/政策面）
  - 知识库目录结构规划
  - 与量化系统的对接方式
