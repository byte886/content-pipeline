## 1. 概述

本文档描述微信客户端的基本UI自动化操作流程，包括窗口管理、搜索操作、鼠标控制最佳实践等。是视频号采集、公众号采集等上层SOP的基础。

**强制选项**：
- 不要最大化微信窗口，保持适当大小
- 窗口位置和大小会随时变化，所有坐标都必须动态计算，不写死

**标准窗口布局规范（任务开始时统一调整）**：

每次任务开始时，应先把微信窗口调整到标准布局，确保后续操作有一致的视觉参考。

**布局原则（优先级从高到低）**：
1. **1级窗口（最高优先级）：主窗口（聊天列表）** — 必须放在最左上角
2. **2级窗口：微信浏览器/搜索结果** — 放在主窗口右侧
3. **3级窗口：其它窗口（朋友圈、视频号等）** — 放在主窗口下方

**排布逻辑**：
- 按优先级从左到右排布
- 如果横向空间不够放了，再往下排
- 所有窗口之间有一定间隔，不重叠
- 每个窗口都要能看到主要操作元素

**触发布局调整的时机**：
1. **任务开始时**：每次新任务开始，先把窗口调整到标准布局
2. **打开新窗口后**：每打开一个新窗口（如搜索结果、朋友圈），都要调整到对应位置
3. **窗口位置混乱时**：如果发现窗口重叠、遮挡严重，重新调整布局
4. **窗口大小变化时**：如果窗口被手动拖动改变了大小，重新调整到标准大小

**1920x1200屏幕下的标准布局参考**：

| 优先级 | 窗口类型 | 位置 | 大小 | 说明 |
|--------|---------|------|------|------|
| 1级 | **主窗口（聊天列表）** | 左上角，x=0, y=0 | 900x600 | 左侧导航栏、聊天列表、搜索框 |
| 2级 | **微信浏览器/搜索结果** | 主窗口右侧，x=900, y=0 | 1010x600 | 搜索结果、公众号页面、视频号页面 |
| 3级 | **其它窗口（朋友圈等）** | 主窗口下方，x=0, y=600 | 900x590 | 朋友圈内容、视频号内容 |

**窗口索引规律**：
- 主窗口通常是 `window 2`（标题"微信"）
- 新打开的子窗口通常是 `window 1`（标题"微信 (窗口)"）
- 朋友圈窗口有自己的标题"朋友圈"
- 注意：窗口索引会随着窗口打开/关闭而变化，调整前先确认窗口标题

**调整方法**：
```bash
# 1. 调整主窗口（window 2）到左上角
osascript <<'OSA'
tell application "System Events"
  tell process "WeChat"
    set size of window 2 to {900, 600}
    set position of window 2 to {0, 0}
  end tell
end tell
OSA

# 2. 调整搜索结果窗口（window 3）到主窗口右侧
osascript <<'OSA'
tell application "System Events"
  tell process "WeChat"
    set size of window 3 to {1010, 600}
    set position of window 3 to {900, 0}
  end tell
end tell
OSA

# 3. 调整朋友圈窗口（window 1）到主窗口下方
osascript <<'OSA'
tell application "System Events"
  tell process "WeChat"
    set size of window 1 to {900, 590}
    set position of window 1 to {0, 600}
  end tell
end tell
OSA
```

**注意**：
- 屏幕分辨率1920x1200下，这个布局能同时看到3个窗口，不需要频繁切换
- 所有窗口都不重叠，每个窗口都能看到主要操作元素
- 如果屏幕更小，优先保证主窗口和第二个窗口的空间，第三个窗口可以适当缩小
- 打开新窗口后，都要按照这个布局调整位置和大小

## 2. 窗口管理

### 2.1 打开微信

```bash
# 用reopen恢复最小化窗口（比activate更可靠）
osascript -e 'tell application "WeChat" to reopen'
sleep 0.3
osascript -e 'tell application "WeChat" to activate'
sleep 0.2

# 确保窗口未最小化
osascript <<'OSA' 2>/dev/null
tell application "System Events"
  tell process "WeChat"
    repeat 2 times
      if (count of windows) > 0 then
        try
          set miniaturized of window 1 to false
          exit repeat
        end try
      end if
      delay 0.2
    end repeat
  end tell
end tell
OSA
```

### 2.2 激活主窗口

```bash
osascript -e 'tell application "System Events" to tell process "WeChat" to set frontmost to true'
sleep 0.5
```

**验证**：菜单栏显示"微信"，关闭按钮（红黄绿）是彩色的。

### 2.3 获取窗口位置和大小

```bash
# 获取窗口位置
osascript -e 'tell application "System Events" to tell process "WeChat" to get position of window 1'
# 输出示例：134, 172

# 获取窗口大小
osascript -e 'tell application "System Events" to tell process "WeChat" to get size of window 1'
# 输出示例：1011, 594
```

### 2.4 调整窗口大小

如果窗口太小（如<600px宽），应先调整到合适大小。

**方法A（推荐，osascript）**：
```bash
osascript <<'OSA'
tell application "System Events"
  tell process "WeChat"
    set size of window 1 to {1000, 600}
    set position of window 1 to {400, 200}
  end tell
end tell
OSA
```

**方法B（备选，鼠标拖动右下角）**：
- 如果osascript不生效（特别是在通讯录页面），用鼠标拖动窗口右下角来调整大小
- 计算窗口右下角位置：x=WIN_X+WIN_W, y=WIN_Y+WIN_H
- 拖动到目标大小：x=WIN_X+目标宽度, y=WIN_Y+目标高度
- 用cliclick拖拽：`cliclick dd:x1,y1 dm:x2,y2 du:x2,y2`

**验证**：调整后截图确认，确保搜索框和聊天列表都能正常显示。

### 2.5 前置窗口（搜索窗口被主窗口盖住时）

```bash
# 方法1：AppleScript AXRaise
osascript -e 'tell application "System Events" to tell process "WeChat" to perform action "AXRaise" of window 2'

# 方法2：Computer use
# cu.perform_secondary_action("com.tencent.xinWeChat", element_index, "AXRaise")
```

### 2.6 关闭标签页

```bash
# 用Cmd+W快捷键关闭当前标签页
osascript -e 'tell application "System Events" to keystroke "w" using {command down}'
```

**注意**：如果只有主窗口，Cmd+W会关闭整个微信窗口，需要用reopen重新打开。

## 3. 导航操作

### 3.1 切回聊天列表状态

如果在收藏/通讯录状态，需要切换到聊天状态。

**已验证的左侧导航栏快捷键（Cmd+数字）**：

| 快捷键 | 对应功能 | 图标位置（从上到下） | 验证结果 |
|--------|----------|----------------------|----------|
| **Cmd+1** | 聊天 | 第1个：聊天气泡 | ✅ 已验证 |
| **Cmd+2** | 通讯录 | 第2个：人形轮廓 | ✅ 已验证 |
| **Cmd+3** | 收藏 | 第3个：文件夹 | ✅ 已验证 |
| **Cmd+4** | 朋友圈 | 第4个：圆环形状 | ✅ 已验证（会打开新窗口） |
| **Cmd+5~Cmd+9** | 无对应功能 | 视频号/小程序/公众号等 | ❌ 测试无变化 |

**方法A（推荐，快捷键，不依赖坐标）**：
- 按 `Cmd+1` 切换到聊天状态
- 按 `Cmd+2` 切换到通讯录状态
- 按 `Cmd+3` 切换到收藏
- 按 `Cmd+4` 打开朋友圈（新窗口）
- 已验证在不同窗口大小下均可靠

**方法B（点击左侧导航栏图标）**：
- 位置：左侧导航栏对应图标
- 注意：坐标会随窗口大小变化，使用前必须动态计算
- 不如快捷键可靠，优先用快捷键

### 3.2 退出聊天输入状态

如果当前在跟某个人聊天，按Tab键是在聊天输入框中切换，不是切换到搜索框。需要先退出聊天输入状态。

**核心原理**：微信的聊天列表中，按上下箭头键可以在不同会话之间切换。如果切换到的会话不是当前正在聊天的（如未打开过的群聊、公众号等），右侧会显示空白，从而退出聊天输入状态。

**方法A（推荐，不依赖坐标，最可靠）：用上下箭头键切换会话**
1. 先点击聊天列表区域获取焦点（点击任意一个会话条目即可）
2. 按向下箭头键（key code 125）切换到下一个会话
3. 观察右侧：如果显示空白的微信图标，说明已退出聊天输入状态
4. 如果右侧仍然显示聊天内容，继续按向下箭头键，直到找到一个未打开过的会话
5. **验证标准**：右侧聊天窗口显示空白的微信图标（没有选中任何聊天项的内容）

**方法B（备选，依赖坐标）：点击聊天列表底部的空白区域**
- 位置：聊天列表最底部的空白区域（最后一个聊天项下方）
- 注意：坐标会随窗口大小变化，使用前必须重新获取窗口位置并动态计算
- 常见错误：点到最后一个聊天项上（会选中该聊天项，而不是退出聊天输入状态）
- 不要点击左侧导航栏的空白区域，那里不能退出聊天输入状态

**为什么不用End键**：End键只是滚动到聊天列表最底部，如果最后一个会话还是聊天，仍然会保持输入状态。上下箭头键是真正切换会话，更可靠。

### 3.3 打开朋友圈

朋友圈是独立窗口，打开后放在主窗口下方。

**操作方法**：
1. 确保主窗口处于聊天状态（Cmd+1）
2. 点击左侧导航栏第4个图标（圆环/波纹形状）
3. 朋友圈窗口会在新窗口中打开

**图标位置**（主窗口左上角为原点，主窗口大小900x600时）：
- x=35, y=285
- 注意：坐标会随窗口大小变化，优先观察图标的相对位置

**验证**：
- 新窗口标题为"朋友圈"
- 窗口中显示朋友圈信息流

## 4. 搜索操作

### 4.1 完整搜索流程

1. **打开微信**（见2.1）
2. **激活主窗口**（见2.2）
3. **切回聊天列表状态**（见3.1，用Cmd+1）
4. **退出聊天输入状态**（见3.2，如果在聊天状态）
5. **激活搜索框**（已验证两种方式均可）：
   - **方式A（推荐，最可靠）：Cmd+F快捷键**
     - 按 `Cmd+F` 激活搜索框
     - 验证：搜索框显示绿色边框+下拉框（搜索网络结果、最近搜索）
     - 优点：不依赖窗口状态，在聊天状态下也能直接激活搜索框
   - **方式B：按Tab键切换**
     - 按3次Tab键
     - 仅在主窗口聊天列表状态下有效，需要先退出聊天输入状态
     - 不如Cmd+F可靠，优先用Cmd+F
6. **输入搜索关键词**（中文用剪贴板方式）：
   ```bash
   echo -n "关键词" | pbcopy
   osascript -e 'tell application "System Events" to keystroke "v" using {command down}'
   ```
   - 注意：osascript keystroke不支持中文，必须用剪贴板方式
7. **触发搜索**（已验证两种方式均可）：
   - **方式A（推荐，更可靠）：向下键+回车**（已验证成功，在不同窗口大小下均可靠）
     - 按向下键选择搜索建议（选中项显示灰色背景）
     - 然后按回车确认
     - 优点：不依赖坐标计算，在不同窗口大小下均可靠
   - **方式B：单击搜索建议**（已验证成功，但坐标需要精确计算）
     - 单击任意一个搜索建议（如"巫师财经"、"巫师财经公众号"）
     - 鼠标按下并及时释放，不要搞成拖拽效果
     - 不需要双击，单击即可触发搜索
     - 注意：在不同窗口大小下，搜索建议的位置会变化，需要重新计算坐标
   - **注意**：直接按回车在搜索框中无效，必须先选择搜索建议
8. **搜索结果页面操作**：
   - 搜索窗口打开后可能被主窗口盖住，需要前置窗口（见2.4）
   - 在搜索结果中找到视频号/公众号条目，点击进入

### 4.2 搜索框替换内容

1. 确保在主窗口聊天列表状态（不是聊天输入状态）
2. 按3次Tab键切换到搜索框
3. 用Cmd+A全选现有内容
4. 用剪贴板粘贴新内容
5. 单击搜索建议触发搜索（鼠标按下并及时释放，不要搞成拖拽效果）

**注意**：不要用退格键删除内容，容易出错。

### 4.3 微信浏览器操作（第二个窗口）

微信浏览器（搜索结果窗口）是第二个窗口，打开后放在主窗口右侧。

#### 4.3.1 在浏览器中直接搜索新内容

1. 激活微信浏览器窗口（前置窗口）
2. 点击浏览器顶部的搜索框
3. 用Cmd+A全选现有内容
4. 用剪贴板粘贴新关键词
5. 按回车触发搜索

**注意**：
- 浏览器中的搜索框和主窗口的搜索框是分开的
- 在浏览器中搜索新内容不需要回到主窗口

#### 4.3.2 识别并打开视频号/公众号链接

1. 在搜索结果页面中，找到视频号或公众号条目
2. **悬停识别**：鼠标移动到条目上，观察是否变成浅灰色高亮
3. **确认灰色状态后再点击**（不要直接点击）
4. 点击后会打开新的标签页或新窗口

**识别要点**：
- 视频号条目：有"视频号"字样，显示视频数量和更新时间
- 公众号条目：有"公众号"字样，显示文章数量和作者信息
- 条目前面有对应的头像/图标

#### 4.3.3 关闭多余的标签页

**原则**：新开搜索时，关闭之前的多余标签页，只保留当前需要的标签页。

**操作方法**：
1. 点击标签页右侧的关闭按钮（×）
2. 或者用快捷键Cmd+W关闭当前标签页

**注意**：
- 不要关闭主窗口标签页
- 关闭前确认标签页标题，不要误关需要的页面
- 保留当前正在使用的标签页，关闭其它多余的

## 5. 鼠标控制最佳实践（混合方案）

> **原则**：以Computer use为主，cliclick为辅，结合两者优点。

### 5.1 工具选择

| 操作类型 | 推荐工具 | 原因 |
|---------|---------|------|
| 状态观察（截图、AX树） | Computer use | 稳定、返回UI状态 |
| 键盘操作（Tab、Cmd+V、回车） | Computer use | 稳定、不报错 |
| 鼠标点击 | cliclick | 更可靠、不报错 |
| 鼠标悬停 | cliclick（m:x,y只移动不点击） | 截图不显示鼠标指针，需仔细观察 |
| 窗口管理（前置、打开） | AppleScript（AXRaise、reopen） | 稳定可靠 |

### 5.2 坐标计算原则

1. **始终基于当前窗口位置动态计算，不写死坐标**
2. 获取窗口位置：`osascript -e 'tell application "System Events" to tell process "WeChat" to get position of window 1'`
3. 获取窗口大小：`osascript -e 'tell application "System Events" to tell process "WeChat" to get size of window 1'`
4. **Retina显示器注意**：截图是物理像素，cliclick用逻辑点，需除以backingScaleFactor（通常2.0）
5. 当前屏幕1920x1200，非Retina，缩放因子1

### 5.3 点击验证原则（必须遵守）

1. **点击前先截图** - 不要盲目点击
2. **点击后截图** - 验证是否成功
3. **一个动作后验证** - 不要连续点击5次不检查
4. **瞄准按钮中心** - 而不是边缘，确保可靠点击
5. **鼠标点击不要刚好到边界，要过一点**

### 5.4 悬停灰色状态识别

- 视频号/公众号条目悬停时会变成浅灰色高亮
- 灰色很浅，需要仔细观察对比截图
- 用cliclick m:x,y移动鼠标（只移动不点击），然后截图确认
- 确认灰色状态后再点击

### 5.5 cliclick常用命令

```bash
# 单击
cliclick c:x,y

# 双击（一般不需要，单击即可触发搜索）
cliclick dc:x,y

# 右键点击
cliclick rc:x,y

# 移动鼠标（不点击）
cliclick m:x,y

# 拖拽
cliclick dd:x1,y1 dm:x2,y2 du:x2,y2
```

## 6. 坐标计算原则与示例

> **重要原则**：窗口的大小和位置会随时变化，SOP中不写死坐标。所有坐标都必须基于当前窗口位置动态计算。以下只是历史验证过的示例，仅供参考。

### 6.1 动态坐标计算方法

```bash
# 1. 获取当前窗口位置
WIN_POS=$(osascript -e 'tell application "System Events" to tell process "WeChat" to get position of window 1')
WIN_X=$(echo $WIN_POS | cut -d',' -f1 | tr -d ' ')
WIN_Y=$(echo $WIN_POS | cut -d',' -f2 | tr -d ' ')

# 2. 获取当前窗口大小
WIN_SIZE=$(osascript -e 'tell application "System Events" to tell process "WeChat" to get size of window 1')
WIN_W=$(echo $WIN_SIZE | cut -d',' -f1 | tr -d ' ')
WIN_H=$(echo $WIN_SIZE | cut -d',' -f2 | tr -d ' ')

# 3. 根据相对位置计算屏幕坐标
# 例如：聊天图标在窗口内相对位置 x=30, y=145
CHAT_X=$((WIN_X + 30))
CHAT_Y=$((WIN_Y + 145))
```

### 6.2 历史验证过的相对坐标示例

> 以下相对坐标基于特定窗口大小验证，实际使用时需要根据当前窗口大小调整。

| 操作 | 相对坐标（窗口内） | 说明 |
|------|------------------|------|
| 聊天图标 | x=30, y=145 | y=130偏高，y=80点到头像 |
| 搜索框 | 顶部居中 | 按3次Tab键到达，不需要坐标 |
| 搜索建议 | 不推荐用坐标 | 推荐用向下键+回车触发搜索 |
| 聊天列表区域 | x=200, y=300 | 用于获取焦点，然后按上下箭头键 |

### 6.3 优先使用不依赖坐标的操作

| 操作 | 推荐方法（不依赖坐标） | 原因 |
|------|----------------------|------|
| 退出聊天输入状态 | 上下箭头键切换会话 | 窗口大小变化时仍然可靠 |
| 触发搜索 | 向下键+回车 | 窗口大小变化时仍然可靠 |
| 切换到搜索框 | 按3次Tab键 | 窗口大小变化时仍然可靠 |
| 关闭标签页 | Cmd+W | 不依赖坐标 |
| 中文输入 | 剪贴板方式（pbcopy+Cmd+V） | 不依赖坐标 |

## 7. 常见问题

### Q: 按Tab键没有反应？
A: 检查是否在聊天输入状态。如果当前在跟某个人聊天，需要先退出聊天输入状态：
- **推荐方法（不依赖坐标）**：点击聊天列表区域获取焦点，然后按上下箭头键切换到另一个会话，直到右侧显示空白的微信图标
- 备选方法：点击**聊天列表底部的灰色空白区域**（最后一个聊天项下方），但坐标需要动态计算
- 注意：不是左侧导航栏的空白区域，那里不能退出聊天输入状态
- 注意：End键只是滚动到最底部，如果最后一个会话还是聊天，仍然会保持输入状态，不推荐

### Q: 如何快速激活搜索框？
A: **推荐用Cmd+F快捷键**，比按Tab键3次更可靠。Cmd+F在任何状态下都能直接激活搜索框，不需要先退出聊天输入状态。已验证在不同窗口大小和位置下均稳定可靠。

### Q: 点击搜索建议没有触发搜索？
A: 需要**单击**搜索建议（鼠标按下并及时释放，不要搞成拖拽效果）。**已验证单击即可触发搜索，不需要双击**。或者按向下键选择后按回车。如果单击没反应，检查是否点到了条目边缘，尝试瞄准条目中心位置。

### Q: 搜索窗口被主窗口盖住了？
A: 用AXRaise动作前置窗口：`osascript -e 'tell application "System Events" to tell process "WeChat" to perform action "AXRaise" of window 2'`

### Q: Computer use报错COMPUTER_USE_V2_SCREENSHOT_STALE？
A: 这是截图过期错误，重试即可。如果频繁出现，改用cliclick进行鼠标点击操作。

### Q: 多个窗口同时使用Computer use导致冲突？
A: 报错"user is operating the target application"。确保只有一个任务在使用Computer use控制微信。

### Q: Cmd+W关闭了整个微信窗口？
A: 如果只有主窗口，Cmd+W会关闭整个微信。用`osascript -e 'tell application "WeChat" to reopen'`重新打开。

### Q: 误发消息到聊天窗口？
A: 确保在搜索框输入，而不是在聊天输入框输入。输入前验证搜索框是否有绿色边框。

### Q: 中文输入失败？
A: osascript keystroke不支持中文，必须用剪贴板方式（pbcopy + Cmd+V）。
