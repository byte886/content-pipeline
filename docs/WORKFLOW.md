# 项目工作流（WORKFLOW）

> **文档类型**：Process（流程规范）
> **更新频率**：流程变更时
> **维护者**：AI自动维护 + 用户审核
> **读者**：AI代理（执行任务前必读）

> 本文档是项目的整体工作流概览，定义从采集到交付的四阶段流水线及各阶段校验门。
> 各平台、各行业的详细SOP见参考文档链接，本文档只放概览和校验门，不重复细节。

---

## 整体流水线

```
阶段① 资源采集 → 阶段② 内容处理 → 阶段③ 知识提取 → 阶段④ 知识库组织与交付
   (采集)          (处理)           (提取)            (交付)
```

| 阶段 | 目标 | 核心产出 | 校验门 |
|------|------|---------|--------|
| ① 资源采集 | 从各平台采集原始视频/图文 | 短视频mp4、文章、视频清单 | 数量对账、文件完整性 |
| ② 内容处理 | 把音视频和图片变成可搜索的文字 | 转写稿md、关键帧、OCR文字 | 转写覆盖率、OCR准确率 |
| ③ 知识提取 | 按行业提取结构化知识 | 股票观点/珠宝知识/视频创作方法 | 提取完整性、去重 |
| ④ 知识库组织与交付 | 组织成可用知识库并增量更新 | 知识库汇总、状态追踪清单 | 知识库可查询、增量一致 |

---

## 阶段①：资源采集（按平台分）

### 支持的平台
| 平台 | 采集方式 | 状态 | 详细SOP |
|------|---------|------|---------|
| 微信视频号 | MITM代理捕获URL → 下载解密 | ✅ 已跑通 | `wechat-channels-collect-sop.md` |
| B站 | 游客态翻页 + 直连限速 | ✅ 已接入 | `platforms/bilibili/` |
| 抖音 | 浏览器直读video流（绕过403） | ✅ 已跑通 | `platforms/douyin/README.md` |
| YouTube | 复用技能yt-dlp + 代理 | 🔧 待接入 | 技能内参考文档 |

### 采集子环节（通用）
1. **全量列表收集**：遍历作者主页，收集所有视频标题+URL，去重
2. **分类预判**：按标题自动分品类、价值等级、处理需求（是否要OCR/截图）
3. **状态清单生成**：Excel记录每个视频的下载/转写状态，作为增量更新基准
4. **批量下载**：按人类节奏（每5个歇30秒）防风控

### 校验门
- [ ] 全量视频数量与主页显示一致
- [ ] 状态清单已生成，含标题/URL/品类/价值等级/处理需求
- [ ] 已下载的视频文件可正常播放

---

## 阶段②：内容处理（通用能力）

### 通用处理流程
1. **语音转写**：FunASR本地离线转写 → 输出transcript.md
2. **智能关键帧抽取**：镜头检测+清晰度评分+dHash去重，自动挑最清晰的帧
3. **画面OCR**：macOS Vision识别画面上的文字（PPT/图表/参数）
4. **行业插件**：按行业自动加处理维度

### 校验门
- [ ] 所有已下载视频都有转写稿
- [ ] 教学类视频已跑OCR
- [ ] 实物展示类视频已截关键帧

---

## 阶段③：知识提取（按行业分）

### 支持的行业
| 行业 | 提取维度 | 详细规则 |
|------|---------|---------|
| 股票/投资 | 市场观点、技术点位、板块机会 | 项目内processing/knowledge_extraction |
| 珠宝鉴赏 | 品类、种水色地工、鉴别要点、价格 | 技能内`references/domain-plugins/jewelry.md` |
| 视频创作 | 运镜、转场、景别、AI提示词 | 技能内`references/domain-plugins/video-creation.md` |

### 校验门
- [ ] 所有转写稿都经过知识提取
- [ ] 提取结果可追溯（标注来源视频）
- [ ] 跨视频相同观点已去重

---

## 阶段④：知识库组织与交付

### 子环节
1. **按行业组织**：股票/珠宝/创作分开存
2. **带图文档**：转写+OCR+关键帧合并成结构化md
3. **增量更新**：基于状态清单，只处理新增视频
4. **备份同步**：本地→网盘/飞书

### 校验门
- [ ] 知识库按行业组织完整
- [ ] 状态清单已更新（下载/转写/路径）
- [ ] 增量采集机制可用

---

## 增量采集（持续运营）
1. 重新拉全量列表 → 与状态清单对比 → 只处理新增
2. 新增视频走①→②→③→④完整流程
3. 更新状态清单和知识库

---

## 异常处理原则

1. **先怀疑AI自身**：端点、参数、ID、文件选取逻辑、最近改动（约九成问题在此）
2. **token/凭证问题最后怀疑**：须有只读请求返回登录超时的硬证据
3. **请求用户重新登录是最后手段**：不要一失败就让用户操作
4. **同一动作失败两次就换通道**：换命令、目录、依赖、实现路径
5. **网络阻断紧急恢复**：`pkill -9 -f video-capture` + 清除系统代理
