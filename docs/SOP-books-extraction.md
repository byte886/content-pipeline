# SOP：电子资料采集与转码

> **适用范围**：所有行业的PDF/PPTX/EPUB/DOCX等电子资料
> **目标**：将外部获取的电子资料统一采集、转码、组织到知识库中

---

## 1. 目录结构

```
library/07_books/
├── raw/                           # 原始文件（不入库）
│   ├── stock/                     # 股票行业
│   └── jewelry/                   # 珠宝行业
├── extracted/                     # 转码后Markdown（知识来源，入库）
│   ├── stock/
│   └── jewelry/
└── 精华/                          # 结构化精华文稿（入库）
    ├── stock/
    └── jewelry/
```

**原则**：raw/ 放原始大文件不入库，extracted/ 放全文Markdown作为知识来源，精华/ 放AI生成的快速阅读版。

---

## 2. 转码流程

### 2.1 工具与用法

统一使用 `scripts/books/batch_extract_books.py`：

```bash
python3 scripts/books/batch_extract_books.py <输入目录> <输出目录>
```

### 2.2 自动提取方式

| 文件类型 | 判断条件 | 提取方式 |
|---|---|---|
| PDF有文本层 | 文本页占比>20% | PyMuPDF直接提取 |
| PDF扫描件 | 文本页占比<20% | Vision OCR（1.5秒/页） |
| PPTX | 所有 | python-pptx提取 |
| DOCX/EPUB | 所有 | 待实现 |

### 2.3 校验门

转码完成后必须检查：页数对账、空页检测、乱码检测、首尾抽样。

---

## 3. 精华提取

对每本转码后的书籍，生成结构化精华文稿：
1. 核心哲学（3-5条）
2. 交易/分析方法（可操作步骤）
3. 经典语录（10-20条）
4. 对量化系统的启示
5. 与其他书籍的对比

位置：`library/07_books/精华/<行业>/`

---

## 4. 常见问题

| 问题 | 解决方案 |
|---|---|
| PDF有文本层但提取乱码 | 检查编码，尝试pdfplumber替代 |
| OCR速度慢 | 先用文本层提取，只对无文本页OCR |
| PPTX图片文字未提取 | 需要OCR PPTX中的图片（待实现） |
| 书籍找不到电子版 | 在知识库中标注"待获取" |
