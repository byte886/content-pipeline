> **文档类型**：架构设计
> **创建时间**：2026-09-15
> **状态**：方案设计
> **目标**：构建A股投资知识库，为量化系统和内容创作提供数据基础

---

## 一、知识库定位

### 1.1 目标

构建一个以微信视频号「交易的游戏」和公众号「顶底之王」为核心数据源的A股投资知识库，服务于：

1. **量化系统**：提供市场观点、技术分析、行业研究等结构化知识
2. **内容创作**：为公众号和视频号文案提供素材和参考
3. **学习研究**：系统化整理投资方法论和实战经验

### 1.2 核心原则

- **本地优先**：所有原始数据和处理结果存储在本地，云盘备份
- **可追溯**：每条知识都能追溯到原始视频/文章
- **结构化**：从非结构化内容中提取结构化知识
- **增量更新**：支持持续采集和知识更新

## 四、数据流转

### 4.1 整体流程

```
采集 → 下载 → 转写/OCR → 知识提取 → 结构化存储 → 应用
```

### 4.2 详细流程

#### 阶段1：采集
- **视频号**：MITM代理捕获视频URL → 下载 → 解密
- **公众号**：微信数据库/网页抓取 → 文章HTML → 正文提取

#### 阶段2：预处理
- **视频**：提取音频 → FunASR转写 → 文字稿
- **图文**：正文提取 → 图片OCR → 结构化Markdown

#### 阶段3：知识提取
- **市场观点**：从内容中提取对大盘、板块、个股的判断
- **技术分析**：提取关键点位、指标、形态
- **行业研究**：提取行业逻辑、龙头公司、催化剂
- **投资方法论**：提取操作原则、风控规则、选股标准
- **股票池**：提取提到的个股及相关逻辑

#### 阶段4：结构化存储
- 每条知识包含：内容、来源、时间、标签、置信度
- 支持按主题、时间、标的检索

#### 阶段5：应用
- **量化系统**：提供情绪指标、观点汇总、行业热度
- **内容创作**：提供素材库、文案参考、选题建议
- **学习研究**：提供系统化知识、案例库、方法论总结

## 五、知识提取方案

### 5.1 视频内容提取

#### 短视频（3-10分钟）
- **结构**：通常包含市场回顾、当前判断、操作建议
- **提取要点**：
  - 大盘观点（看涨/看跌/震荡）
  - 关键点位（支撑位、压力位）
  - 板块机会
  - 个股推荐及逻辑
  - 操作建议（仓位、买卖点）

#### 直播回放（1-3小时）
- **结构**：通常包含系统教学、实时答疑、案例分析
- **提取要点**：
  - 教学内容（方法论、技术指标）
  - 答疑汇总（常见问题、典型错误）
  - 案例分析（个股操作、板块逻辑）
  - 互动精华（观众提问、老师解答）

### 5.2 图文内容提取

#### 公众号文章
- **结构**：标题、导语、正文、结论
- **提取要点**：
  - 核心观点
  - 数据支撑
  - 逻辑链条
  - 图表信息（OCR）
  - 操作建议

### 5.3 提取工具

- **初步方案**：使用大模型（LLM）进行知识提取
- **输入**：转写稿/文章正文
- **输出**：结构化JSON（观点、标的、点位、标签等）
- **批量处理**：支持批量提取，带缓存和断点续跑

## 六、知识库内容组织

### 6.1 按主题分类

| 分类 | 内容 | 示例 |
|------|------|------|
| 市场观点 | 对大盘的判断和预测 | "A股如期反弹，反弹仅仅是开始" |
| 技术分析 | 技术指标、形态、点位 | "支撑位3000点，压力位3200点" |
| 行业研究 | 行业逻辑、龙头、催化剂 | "新能源板块的投资机会" |
| 投资方法论 | 操作原则、风控、选股 | "如何设置止损位" |
| 股票池 | 提到的个股及逻辑 | "关注XX股票，原因是..." |
| 术语表 | 专业术语解释 | "什么是顶背离" |

### 6.2 按时间组织

- 每日市场观点汇总
- 每周复盘
- 每月总结
- 年度回顾

### 6.3 按标的组织

- 个股档案（提到该股票的所有内容）
- 板块档案（提到该板块的所有内容）

## 七、与量化系统对接

### 7.1 数据接口

- **REST API**：提供知识库查询接口
- **数据导出**：支持CSV/JSON导出
- **实时更新**：新内容采集后自动提取并更新

### 7.2 量化应用场景

1. **情绪指标**：统计视频/文章中看涨/看跌的比例
2. **板块热度**：统计各板块被提及的频率
3. **个股关注度**：统计个股被提及的频率和观点
4. **关键点位**：汇总技术分析中的支撑/压力位
5. **事件驱动**：提取重要事件和催化剂
