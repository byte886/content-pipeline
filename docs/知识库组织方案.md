## 一、知识库定位

### 1.1 目标

构建一个**多平台、多行业**的知识库，服务于：

1. **量化系统**：提供市场观点、技术分析、行业研究等结构化知识
2. **内容创作**：为公众号和视频号文案提供素材和参考
3. **学习研究**：系统化整理行业知识和实战经验
4. **方法提炼**：分析优秀博主的创作方法，提炼可复用的生成技巧

### 1.2 核心原则

- **本地优先**：所有原始数据和处理结果存储在本地，云盘备份
- **可追溯**：每条知识都能追溯到原始视频/文章和处理步骤
- **结构化**：从非结构化内容中提取结构化知识（OKF v0.2格式）
- **增量更新**：支持持续采集和知识更新（水位机制）
- **行业隔离**：不同行业（股票/珠宝）有独立的知识库和创作规则
- **单一权威源**：每个主题只有一个权威文档，其他只链接不复制

## 四、数据流转

### 4.1 整体流程

```
采集（platforms/） → 处理（processing/） → 原始层（library/01-04,06-08） → 知识层（library/05） → 应用层（domains/）
```

### 4.2 详细流程

#### 阶段1：采集
- **视频号**：MITM代理捕获视频URL → 下载 → ISAAC64解密
- **公众号**：微信数据库读取 → 文章HTML → 正文提取
- **B站/抖音/YouTube**：yt-dlp/wbi签名 → 下载

#### 阶段2：预处理
- **视频**：提取音频 → FunASR转写 → 文字稿
- **图文**：正文提取 → 图片OCR（macOS Vision） → 结构化Markdown

#### 阶段3：知识提取
- **内容知识**：市场观点、技术分析、行业研究、投资方法论（按行业定制）
- **方法知识**：拍摄技巧、AI工具使用、内容结构、视觉风格、节奏控制（MethodNote）
- **书籍精华**：推荐书籍的核心观点整理

#### 阶段4：结构化存储（OKF v0.2）
- 每条知识包含：内容、来源、时间、标签、置信度
- 支持按主题、时间、标的、行业检索

#### 阶段5：应用
- **量化系统**：情绪指标、观点汇总、行业热度
- **内容创作**：素材库、文案参考、选题建议、方法参考
- **学习研究**：系统化知识、案例库、方法论总结

## 五、OKF知识格式（v0.2）

所有知识成品统一采用OKF v0.2标准frontmatter：

```yaml
---
type: VideoNote | ArticleNote | BookNote | ReportNote | MethodNote
title: 标题
description: 一句话摘要
tags: [标签1, 标签2]
sources:
  - {id: source-001, resource: "../../04_transcript/xxx.md", title: "原始视频标题"}
generated: {process: knowledge-build, at: "2026-09-15T10:00:00+08:00"}
status: stable | draft | deprecated
stale_after: "2027-03-31T23:59:59+08:00"
domain: stock | jewelry | general
---
```

### 各类型说明

| 类型 | 用途 | 示例 |
|------|------|------|
| VideoNote | 视频内容的知识整理 | 短视频核心观点+关键数据+知识点 |
| ArticleNote | 图文内容的知识整理 | 文章摘要+核心观点+数据支撑 |
| BookNote | 书籍精华整理 | 核心观点+章节摘要+金句 |
| ReportNote | 研究报告整理 | 行业分析+数据+结论 |
| MethodNote | 创作方法提炼 | 拍摄技巧+AI使用+内容结构+分步生成方法 |
| ChapterIndex | 主题融合页 | 某主题下的所有知识索引 |

## 六、文件命名规范

### 6.1 通用格式

```
YYYY-MM-DD_标题.md
```

**规则**：
- 日期优先，方便按时间排序
- 标题简洁，不超过30个字符
- 用中文，不用拼音
- 特殊字符用空格代替（#、/等）

### 6.2 各类型命名

| 类型 | 路径 | 命名示例 |
|------|------|----------|
| 短视频转写 | `04_transcript/wechat_channels/` | `2026-09-01_A股如期反弹.md` |
| 直播回放转写 | `04_transcript/wechat_channels/` | `2026-09-01_周末深度复盘.md` |
| 视频笔记 | `05_knowledge/concepts/videos/` | `2026-09-01_A股如期反弹_VideoNote.md` |
| 图文笔记 | `05_knowledge/concepts/articles/` | `2026-09-01_大盘底部特征_ArticleNote.md` |
| 方法笔记 | `05_knowledge/concepts/methods/` | `2026-09-01_广告博主拍摄技巧_MethodNote.md` |

## 七、标签体系

### 7.1 股票行业标签

**一级标签（必选）**：

| 标签 | 说明 |
|------|------|
| 市场分析 | 大盘走势、指数分析 |
| 板块研究 | 行业板块、概念板块 |
| 个股点评 | 具体股票分析 |
| 技术分析 | 技术指标、K线形态 |
| 投资理念 | 投资哲学、心态管理 |
| 宏观经济 | 政策、利率、通胀 |
| 量化交易 | 策略、回测、因子 |

**二级标签（可选，多选）**：
- 技术指标：MACD、KDJ、RSI、布林带、均线、成交量
- 板块概念：券商、科技、新能源、消费、医药、半导体、AI
- 市场状态：牛市、熊市、震荡、底部、顶部、反弹、突破
- 交易策略：趋势跟踪、均值回归、波段操作、止损、仓位管理

### 7.2 珠宝行业标签

**一级标签（必选）**：

| 标签 | 说明 |
|------|------|
| 宝石学 | 宝石性质、鉴定、分类 |
| 鉴定方法 | 检测技术、鉴别特征 |
| 市场趋势 | 价格走势、供需分析 |
| 选购指南 | 购买建议、避坑指南 |
| 设计工艺 | 镶嵌、切割、设计风格 |
| 文化历史 | 宝石文化、历史故事 |

### 7.3 通用标签

- 方法提炼：拍摄技巧、AI工具、内容结构、视觉风格、节奏控制
- 内容类型：教程、评测、开箱、Vlog、直播、访谈

### 7.4 标签使用规则

- 每条内容至少2个标签，最多5个
- 一级标签必选1个，二级标签可选
- 标签用中文，通用术语可用英文（如MACD）
- 新增标签需要在对应行业的标签清单中登记

## 八、知识提取方案

### 8.1 视频内容提取

#### 短视频（3-10分钟）
- **结构**：通常包含市场回顾、当前判断、操作建议
- **提取要点**：
  - 核心观点（看涨/看跌/震荡）
  - 关键点位（支撑位、压力位）
  - 板块机会
  - 个股推荐及逻辑
  - 操作建议（仓位、买卖点）

#### 直播回放（1-3小时）
- **结构**：通常包含系统教学、实时答疑、案例分析
- **提取要点**：
  - 教学内容（方法论、技术指标）
  - 答疑汇总（常见问题、典型错误）
  - 案例分析（个股操作、板块逻辑）

### 8.2 图文内容提取

#### 公众号文章
- **结构**：标题、导语、正文、结论
- **提取要点**：
  - 核心观点
  - 数据支撑
  - 逻辑链条
  - 图表信息（OCR）
  - 操作建议

### 8.3 方法提炼（MethodNote）

- **场景**：分析优秀博主的创作方法
- **提取维度**：
  1. 拍摄技巧（镜头、运镜、布光）
  2. AI工具使用（哪些工具、怎么用、参数设置）
  3. 内容结构（开头钩子/主体展开/结尾引导）
  4. 视觉风格（色调、构图、字幕样式、转场）
  5. 音频风格（配音、背景音乐、音效）
  6. 节奏控制（剪辑节奏、信息密度、时长控制）
  7. 分步生成方法（可复现的生成步骤）
- **输出**：可操作的生成步骤，能指导实际创作

### 8.4 提取工具

- **初步方案**：使用大模型（LLM）进行知识提取
- **输入**：转写稿/文章正文
- **输出**：结构化JSON（观点、标的、点位、标签等）
- **批量处理**：支持批量提取，带缓存和断点续跑

## 九、质量标准

### 9.1 转写质量

- 准确率≥90%（专业术语正确）
- 无明显错别字
- 数字、专有名词必须准确
- 说话人标注（直播回放多人时）

### 9.2 文章提取质量

- 正文完整（不含广告、无关推荐）
- 图片保留（有OCR结果）
- 发布时间准确
- 作者信息完整

### 9.3 知识点质量

- 定义准确（有来源支撑）
- 有实战案例（至少1个）
- 有操作策略（可执行）
- 有相关内容链接

### 9.4 方法笔记质量

- 有可操作的生成步骤
- 有具体的工具名称和参数
- 有示例参考
- 可复现（按照步骤能生成类似内容）

## 十、与量化系统对接

### 10.1 数据接口

- **REST API**：提供知识库查询接口（未来）
- **数据导出**：支持CSV/JSON导出
- **实时更新**：新内容采集后自动提取并更新

### 10.2 量化应用场景

1. **情绪指标**：统计视频/文章中看涨/看跌的比例
2. **板块热度**：统计各板块被提及的频率
3. **个股关注度**：统计个股被提及的频率和观点
4. **关键点位**：汇总技术分析中的支撑/压力位
5. **事件驱动**：提取重要事件和催化剂
