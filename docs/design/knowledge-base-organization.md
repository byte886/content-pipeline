## 一、核心定位与原则

### 1.1 服务目标

1. **量化系统**：市场观点、技术分析、行业研究等结构化知识
2. **内容创作**：公众号/视频号文案素材
3. **学习研究**：系统化行业知识
4. **方法提炼**：分析优秀博主创作方法，提炼可复用技巧

### 1.2 核心原则

- **本地优先**：原始数据和处理结果存本地，云盘备份
- **可追溯**：每条知识可追溯到原始内容和处理步骤
- **结构化**：OKF v0.2格式
- **增量更新**：水位机制
- **行业隔离**：不同行业独立知识库和创作规则
- **单一权威源**：每个主题只有一个权威文档

---

## 二、OKF知识格式（v0.2）

所有知识成品统一采用OKF v0.2标准frontmatter：

```yaml
---
type: VideoNote | ArticleNote | BookNote | ReportNote | MethodNote
title: 标题
description: 一句话摘要
tags: [标签1, 标签2]
sources:
  - {id: source-001, resource: "../../04_transcript/xxx.md", title: "原始标题"}
generated: {process: knowledge-build, at: "2026-09-15T10:00:00+08:00"}
status: stable | draft | deprecated
stale_after: "2027-03-31T23:59:59+08:00"
domain: stock | jewelry | general
---
```

| 类型 | 用途 |
|------|------|
| VideoNote | 视频内容知识整理 |
| ArticleNote | 图文内容知识整理 |
| BookNote | 书籍精华整理 |
| ReportNote | 研究报告整理 |
| MethodNote | 创作方法提炼 |
| ChapterIndex | 主题融合页 |

## 三、文件命名规范

**通用格式**：`YYYY-MM-DD_标题.md`

- 日期优先，方便按时间排序
- 标题简洁，不超过30字符
- 用中文，特殊字符用空格代替

## 四、标签体系

### 4.1 股票行业

**一级标签（必选1个）**：
市场分析 / 板块研究 / 个股点评 / 技术分析 / 投资理念 / 宏观经济 / 量化交易

**二级标签（可选，多选）**：
- 技术指标：MACD、KDJ、RSI、布林带、均线、成交量
- 板块概念：券商、科技、新能源、消费、医药、半导体、AI
- 市场状态：牛市、熊市、震荡、底部、顶部、反弹、突破
- 交易策略：趋势跟踪、均值回归、波段操作、止损、仓位管理

### 4.2 珠宝行业

**一级标签（必选1个）**：
宝石学 / 鉴定方法 / 市场趋势 / 选购指南 / 设计工艺 / 文化历史

### 4.3 标签规则

- 每条内容至少2个标签，最多5个
- 一级标签必选1个，二级标签可选
- 新增标签在对应行业清单中登记

## 五、知识提取要点

### 5.1 视频内容

| 类型 | 提取要点 |
|------|---------|
| 短视频（3-10分钟） | 核心观点、关键点位、板块机会、个股推荐、操作建议 |
| 直播回放（1-3小时） | 教学内容、答疑汇总、案例分析 |

### 5.2 图文内容

公众号文章：核心观点、数据支撑、逻辑链条、图表信息（OCR）、操作建议

### 5.3 方法提炼（MethodNote）

7个维度：拍摄技巧、AI工具使用、内容结构、视觉风格、音频风格、节奏控制、分步生成方法

## 六、质量标准

| 环节 | 标准 |
|------|------|
| 转写 | 准确率≥90%，专业术语正确，数字准确 |
| 文章提取 | 正文完整，图片有OCR，发布时间准确 |
| 知识点 | 有来源支撑，有实战案例，有操作策略 |
| 方法笔记 | 有可操作步骤，有具体工具和参数，可复现 |

## 七、应用对接

### 7.1 量化系统

- 情绪指标：看涨/看跌比例统计
- 板块热度：各板块提及频率
- 个股关注度：个股提及频率和观点
- 关键点位：支撑/压力位汇总

### 7.2 内容创作

- 素材库：金句、案例、数据、方法笔记
- 文案辅助：选题建议、历史文案参考、标题优化
