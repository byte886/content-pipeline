# library（数据层）— 原始资源 + 知识成品

> **文档类型**：Reference（参考资料 — 数据层导航）
> **更新频率**：目录结构变更时
> **维护者**：AI 自动维护 + 用户审核

> 本目录是 content-pipeline 的**本地唯一权威源**（用户拍板：本地仓库 = 权威源，云文档 = 展示/协作层，出入以本地为准）。
> 大文件（视频/音频/PDF/Office/图片）与中间物**不入库**（gitignore，走本地 + 百度网盘镜像）；入库的只有台账、元数据与清洗后的知识成品。

## 编号体系表

| 编号 | 目录 | 用途（一句话） |

| 02_audio | 原始音频 | 按行业/主题存放音频素材（播客/录音等，本地，不入库） |

| 04_transcript | 转写稿 | FunASR 转写/OCR 文本等中间物，按行业/博主分目录（本地，不入库） |
