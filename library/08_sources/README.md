## 入库策略

评论 JSON 等结构化来源数据入 08_sources（小体量/可追溯）；原始媒体（视频/音频/大文件）本地持有不入库。

> 即：入库的是评论导出、图文、PDF 提取文本等**结构化/小体量**来源数据；`*/raw` 与 `*/cleaned` 等大文件/中间物按 `.gitignore` 本地持有，不入库。
