一、行业术语速查

看懂帖子、与供应商/客户对话前先掌握这些行话。

4C
钻石/培育钻分级四要素：颜色 Color（D 最佳，逐档变黄）、净度 Clarity（FL/IF→VVS→VS→SI→I，SI2 以下不建议）、切工 Cut（3EX 最佳，唯一受人为影响）、重量 Carat（1 克拉=0.2 克=100 分）。
GIA / IGI / NGTC
三类常见证书：GIA 为天然钻最权威国际证书，腰棱有镭射编码、一钻一码；IGI 常用于培育钻石；NGTC 是国内国检（水贝可出证，约 50 元/张，黄金钻饰常用）。警惕"套证钻"。
培育钻石
实验室培育，化学成分、硬度与天然钻完全一致，带 IGI/GIA 证书、可复检；价格约为同参数天然钻的 1/10–1/20（1 克拉含戒托常见 4000–5000 元）。
莫桑石 / 锆石
钻石仿品，成本极低（莫桑样品戒几百元），不是真钻；品牌门店常用莫桑/锆石做陈列样品。过度贪便宜易把天然钻买成莫桑。
种水
翡翠行话，"种"指质地细腻程度、"水"指通透水润度，是翡翠非标定价的核心，新手最易被"灯光效果"误导。
开蚌
直播间现场开珍珠蚌取珠的新奇特玩法，曾在抖音/TikTok 爆火；因带赌博、杀生属性，后续被各平台限制。
报白 / 入基地
抖音珠宝文玩为定向准入类目，需"报白"（进入白名单）、通常要入驻官方直播基地、一物一证发货，否则易被封店下播。
水贝金价 / 工费 / 附加
水贝按当日"水贝金价"（区别于国际金价、品牌零售价）结算；总价=（水贝金价+工费）×金重+附加费。工费为加工费（代购一般加价 15–35 元/克），"附加"指黄金以外配件（绳、配石等）的费用。
跨境店 / 本土店 / 独立站
TikTok 跨境店由国内发货、本土店用当地公司资质；独立站（如 Shopify）不依赖平台闭环，早期靠账号主页 BIO 链接引流成交。另有全托管/半托管模式。
私域 / CPS
私域指微信个人号/群/朋友圈等可反复免费触达的自有客户池；CPS 指按实际成交分佣（样本中给外部推荐人高达 50%）。
二奢
二手奢侈品（珠宝/腕表/包袋），靠真伪鉴别、信息差与私域复购经营，可与鉴定、回收形成闭环。
生命钻石
用宠物或亲人的骨灰、毛发中的碳元素培育而成的纪念钻石，单颗可售上万元、成本约千元级，是培育钻的情感细分。
标品里选非标
选品口诀：在标准化大类里找带非标溢价的切口（如开蚌半成品），再把非标品标准化交付（定制成成品首饰），兼顾溢价与可复制。

二、产业带速查

货源决定成本底线，就近或建联产业带是多数低成本样本的起点。

产业带主营切入提示
深圳水贝黄金/K金、钻饰、培育钻、彩宝综合全国产能交易核心，含金展/水贝金座银座/特力/兴龙，设 NGTC；可接单后拿货做零库存代购与定制。
佛山平洲翡翠（手镯为主）翡翠集散地、货盘全，适合翡翠直播/私域找一手货与异地分销。
广州华林 / 番禺华林玉器批发；番禺镶嵌加工玉石流通与首饰镶嵌代工，定制类找工厂。
诸暨山下湖淡水珍珠中国珍珠之都，设抖音直播基地（入仓、证书发货），开蚌/成品直播源头。
连云港东海水晶水晶集散中心，玄学水晶/文玩核心货源，需会挑货防以次充好。
汕尾可塘彩宝、水晶/配珠半成品"百亿珠子小镇"，DIY 手串、彩宝配珠货源，成本低、毛利高。
义乌DIY 琉璃珠、饰品配件国际商贸城+福田/兴中/北下朱等，平价饰品/手串直播供应链腹地。
河南柘城等培育钻石培育钻主产区，工厂多不接散客、经多层分销，私域定制玩家的成本洼地。
新疆和田玉产地源头，适合做产地信任型华人/二代珠宝人 IP。

三、平台规则与打法速查

平台打法规则红线 / 提醒
小红书专业知识+款式推荐两类内容立人设，群聊/评论区安全引流微信；低粉可高变现忌站外硬广与明显微信号（用群欢迎语、小号图等相对安全方式并关注规则变化）；精准粉优先，别追泛娱乐粉。
抖音直播+短视频+投流，小众类目（鸡血石/手串/珍珠）竞争小珠宝文玩需报白、入基地、一物一证；盲盒/开蚌/赌石类受限；按退货后真实利润算账。
视频号直播+朋友圈/社群联动，熟人信任，适合熟龄高客单（玉石/黄金/二奢）依托微信生态，重私域复购，内容要契合中老年审美与信任链。
TikTok短视频/直播为店铺引流，店铺精细化运营；莫桑钻、珍珠成品，毛利 30–60%网络需原生住宅 IP 防风控；48h 发货/72h 入仓；盲盒类已不允许；负责人须深度参与。
微信私域朋友圈四圈（生活/思维/产品/代理）+1v1 咨询+复购转介绍+代理裂变高客单收定金控风险、明确定制不退、贵重品顺丰保价；靠产品与服务复利，不刷屏硬卖。

四、从 0 到 1 行动清单

  • 盘点资源：是否近产业带、有无私域/资质、能否出镜或写图文、资金厚薄，据此选 1 个窄切口，不一开始多平台铺开。
  • 数据化选品：在别人近 1–2 月已验证的爆款里选（赞藏评达标、可模仿），建爆品库，不凭个人审美测款；优先高客单高毛利。
  • 筛供应商 4 判据：回复速度快、懂 3C/切工/克重、报价即时（不转手问上线）、支持来图甚至手绘定制；同时询 3–4 家比价。
  • MVP 验证：几千元货 + 现成场地，一周内开播/上架跑通最小闭环；有数据立即小步迭代（如调活动力度），不追求一次完美。
  • 立人设做内容：专业（懂行避坑）+靠谱（长期主义）+明确利益点；只做"专业知识占心智 + 款式推荐做销售"两类内容。
  • 引流私域成交：公域只立人设、合规引流；私域承接信任，定制先收接近成本的定金、量准圈口号、当天锁金价。
  • 复购与裂变：质检、包装、终身售后超预期；老客友情价不打折；用代理合伙人与 CPS（推荐分佣）放大转介绍。
  • 放大先复制：单点盈利后优先复制同模型账号/直播间，而非租大场地、招大批人的"扩张"；算清创始人时薪。
  • 设定止损线：当低价玩家大量涌入、头部转型、自身流量结构性下滑时，果断清仓退场，保住已得利润。

五、高频避坑红线

  • 忌重资产贪大：模式没跑通前不租大店、不扩招、不囤大量 SKU（两个样本因此亏 200 万 / 压货几十万）。
  • "发货即盈利"是假象：珠宝直播退货率可达 20%+，必须按 10 天退货后的真实利润算账。
  • 网红坑位费风险前置：数万坑位费+15–25% 佣金，爆款利润率不足 10% 也会亏；普通人优先自播做小 IP。
  • 认证书防造假：认 GIA 腰棱镭射码、IGI/NGTC 证书并支持复检，防套证钻、莫桑冒充、金重不达标。
  • 0–1 阶段不迷信代运营：自己没有内容/运营能力时，代运营无法替你从 0 到 1，样本中 1.4 万元代运营费打水漂。
  • 跑通前不增加任何额外投入：样品可用莫桑等低成本材料替代真钻出图，先验证需求再备货。
  • 不碰合规红线：赌石/盲盒/开蚌等"贴线玩法"随规则收紧，玄学内容主打文化疗愈、不碰封建迷信表述。
