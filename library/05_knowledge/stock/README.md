## 二、单条 JSON 的字段（提取了什么）

每条 `short_###_<标题>.json` / `live_###_<标题>.json` 含：

| 字段 | 含义 |
|---|---|
| `video_id` / `title` | 视频编号与标题 |
| `extracted_at` | 提取时间 |
| `transcript_length` | 转写正文字数 |
| `market_view` | 行情观点：`direction`（看涨/看跌/震荡）、`confidence`（置信度）、`bullish_signals` / `bearish_signals`（多空信号） |
| `technical_levels` | `support` 支撑位 / `resistance` 阻力位 |
| `sector_opportunities` | 提到的板块机会 |
| `stock_mentions` | 提到的个股 |
| `trading_advice` | 操作建议（仓位 `position` / 动作 `action`） |
| `key_quotes` | 关键原话（金句） |
| `tags` | 主题标签 |

### 汇总统计能回答什么

`knowledge_base_summary.json` 已对全库做了情绪与板块聚合，例如全库方向分布（看涨 149 / 震荡 135 / 看跌 52）、热门板块（银行等）。可用于：
- 统计某博主在一段时间内的**多空倾向与板块偏好**；
- 汇总其反复给出的**支撑/阻力位与个股提及频次**；
- 作为"市场情绪/观点"研究的结构化语料。

> ⚠️ 这些是**博主个人在历史时点的行情判断**，不是客观事实、更非投资建议；方向/点位随行情失效，使用时必须带时间戳并注明"一方观点，不构成投资建议"。
