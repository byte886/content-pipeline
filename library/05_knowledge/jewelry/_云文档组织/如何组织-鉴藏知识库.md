# 鉴藏知识库 · 如何组织（AI 工作守则）

> **致后来的 AI（新会话 / 新窗口）**：你在维护本知识库（云盘孵化版）时，请先通读本页，按下面规则决定"新增内容放哪、怎么写、怎么保证质量"。本页是总入口，配套《README》看现状，配套《云盘归档与组织规则（AI工作守则）》看云盘整体规则。

---

## 一、总体原则

1. **两类知识分开**：懂货（鉴藏知识）与会讲（内容方法）各成体系，靠双向引用融合，不混在一个目录。
2. **以博主/专家为原点**：一位博主的知识先归成一个 bundle（如 `珠宝学者郭颖/`），再按品类/主题挂入体系；同套路扩展到下一位博主（老许）。
3. **本地仓库 = 权威源**：云文档内容从本地 OKF 仓库（content-pipeline）导入；改内容先改本地，再同步云文档。
4. **每层都要 README**：本页是总入口，每层目录配 README 说明"这是什么、有什么"。

## 二、三层结构（内容放哪）

| 层 | 目录 | 放什么 | 示例 |
|---|---|---|---|
| **L1 鉴藏知识（懂货）** | `01_鉴藏知识/<博主或品类>/` | 收藏/鉴赏的知识成品（OKF 文档，带来源） | `珠宝学者郭颖/钻石-知识文档` |
| **L2 内容方法（会讲）** | `02_内容方法/` | 视频结构/风格运镜/文案话术/音频设计/博主研究 | `博主研究/郭颖研究`（为什么受欢迎） |
| **L3 案例对标（证据）** | `03_案例对标/` | 优秀视频的分析卡片（**只放指针**，不复制视频实体） | 郭颖B级对标卡片（本地 video-studio） |

**判断口诀**：讲"这个东西是什么/怎么鉴别" → L1；讲"这种视频怎么拍/怎么讲" → L2；"某条视频为什么好" → L3。

## 三、新增内容流程

1. **判断类型**：知识 / 方法 / 案例（按口诀）。
2. **放对应目录**：L1 按博主建子目录（新博主先问用户是否开新目录）；L2 按五个子类（视频结构/风格运镜/文案话术/音频设计/博主研究）；L3 放卡片指针。
3. **写/更新 README**：本页 + 所在层 README + 云盘项目 `00_索引`（珠宝电商项目索引 docx）补链接。
4. **标注来源**：四档——已查证 / 经搜索补充 / 博主一方说法 / 未经核实；无法核实标"待补"，禁止编造。
5. **命名**：直接反映内容，成套资料用数字前缀（`01_`、`02_`）。

## 四、质量要求（审查标准）

- **知识文档**：结构清晰（分节+对比表）、逐条来源、〔转写〕〔观点〕待补标注齐全。
- **命名**：一眼看懂、不重复、不堆云盘根。
- **链接**：跨层双向引用、无死链；卡片只放指针不复制实体。
- **对账**：博主视频 → 知识文档全覆盖、零遗漏（参考郭颖《吸收对账》做法）。
- **审查节奏**：每次扩容后对照本页审查；不合格即重构迭代。

## 五、毕业机制

某块内容**真正成型、结构稳定、长期反复复用**时，向用户提议迁入飞书知识库（Wiki）"毕业"；**迁移前必须经用户确认**，迁移后更新本页、清理孵化目录并同步项目索引。
