# 01_鉴藏知识 · 层 README

> **本层是什么**：鉴藏知识（懂货）——收藏/鉴赏的知识体系，按博主/专家为原点组织，成熟后扩充品类。

## 放什么

- 各博主的 OKF 知识文档（带来源、带分级标注）
- 品类知识、实战手册（如郭颖的潘家园淘货实战）
- 博主级"吸收对账"（视频→文档全覆盖记录）

| `珠宝学者郭颖/` | 23 份知识文档 + 吸收对账（192 条视频全覆盖） |

## 维护规则

1. 新增博主 → 先问用户是否开新子目录，再按"如何组织"流程建 bundle。
2. 文档须带 frontmatter（sources/status/type）与〔转写〕〔观点〕待补标注。
3. 新增后更新本层 README 与项目 00_索引。

*详细规则见 `00_组织方法/如何组织-鉴藏知识库`。*
