> **定位**：鉴藏知识体系（珠宝/翡翠/陶瓷/古玩/家具…）的孵化工作台，内容成熟后按"毕业机制"迁入飞书知识库（Wiki）。
> **规则依据**：《云盘归档与组织规则（AI工作守则）》《知识库与云文档·总导航（知识地图）》

## 一、这是什么

知识库分**两类知识、分层组织、各自融合**：

| 层 | 类别 | 一句话 | 目录 |
|---|---|---|---|
| **L1 鉴藏知识（懂货）** | 收藏/鉴赏的知识体系 | 珠宝/翡翠等品类怎么鉴别、分级、避坑 | `01_鉴藏知识/` |
| **L2 内容方法（会讲）** | 如何拍收藏品视频 | 视频结构/风格运镜/文案话术/音频设计/博主研究 | `02_内容方法/` |
| **L3 案例对标（证据）** | 优秀视频的分析卡片 | 好视频拆解成可复用卡片，只放指针 | `03_案例对标/` |

**融合方式**：方法条目 ↔ 案例卡片 ↔ 知识文档互相挂链接（双向引用）。博主研究页是"融合层"——把"讲什么（知识）× 怎么讲（方法）× 为什么有人看（运营归因）"放在一起。

## 四、维护约定

1. 新增知识 → `01_鉴藏知识/<博主或品类>/`；新增创作方法 → `02_内容方法/`；案例卡片 → `03_案例对标/`（只放指针）。
2. 每层配 README；新增重要文档后同步更新本项目 `00_索引`（珠宝电商项目）。
3. 内容从本地 OKF 仓库（content-pipeline）导入，本地=权威源，云文档=展示/协作层。
4. 所有事实标注来源（已查证 / 经搜索补充 / 博主一方说法 / 未经核实）。
5. 定期审查组织与质量，不合格即重构迭代。
