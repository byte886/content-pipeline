## 三、可复用的运营启示（对鉴藏内容生产）

1. **权威 + 接地气双轨**：身份背书建立信任，地摊/开箱场景建立亲近感。
2. **知识资产化**：一个品类沉淀一份文档 → 内容可复用、可引用、可再加工（选题/脚本素材库）。
3. **两类选题搭配**：科普类（信任）与高货类（流量）交替，避免纯科普枯燥、纯猎奇无沉淀。
4. **视频结构可拆解**：开箱估价型 / 高货故事型 / 文化寓意型 / 科普讲货型…… 拆成卡片可直接当脚本模板（见 03_案例对标）。
5. **人设 = 知识 + 风格 + 选题**：运营时三者一起做，缺一不可。
