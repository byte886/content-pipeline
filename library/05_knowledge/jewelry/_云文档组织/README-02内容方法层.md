# 02_内容方法 · 层 README

> **本层是什么**：内容方法（会讲）——如何拍收藏品视频：视频结构、风格运镜、文案话术、音频设计、博主研究。

## 子类

| 子类 | 放什么 |
|---|---|
| `视频结构/` | 分镜模板、片型结构（开箱估价型/高货故事型/科普讲货型…） |
| `风格运镜/` | 运镜手法、镜头语言、视觉风格 |
| `文案话术/` | 口播文案、话术、标题技巧 |
| `音频设计/` | 配乐/音效/人声设计、音频提示词 |
| `博主研究/` | 博主为什么受欢迎 = 运营/创作方法知识（融合层） |

## 当前内容

- `博主研究/郭颖研究-为什么受欢迎`：郭颖账号画像、内容特征、可复用运营启示。

## 维护规则

1. 创作方法一律归本层，不与知识混放。
2. 博主研究页是"融合层"：知识（讲什么）× 方法（怎么讲）× 运营（为什么有人看）。
3. 新增后更新本层 README 与项目 00_索引。

*详细规则见 `00_组织方法/如何组织-鉴藏知识库`。*
