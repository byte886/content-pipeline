# 数字口诀化选题与韵文记忆点

> 一句话定义：把专业结论压缩成"N 招 / N 问 / 一套押韵口诀"，让观众看完能当场复述、转头就能用——选题本身就是记忆钩子。

## 模式（原则）

1. **数字封题**：标题直接给数量与动作——"三问三不问"[^src-transcript-sanwen]、"三招鉴别假黄金"[^src-transcript-sanzhao]，数量本身就是承诺（看完就有几招）。
2. **口诀韵文化**：把复杂价格梯度编成顺口溜——"豆种偏白就几百，糯种一小千，若种带冰五千起……冰种满绿就超百万"[^src-transcript-wanggou]，韵文降低记忆成本。
3. **先排雷后给法**：先说"三不问"（你这是金子吗/保不保值/有没有优惠=一听就不懂行），再给"应该怎么问"（含量 999 还是 18K、按克卖还是按件卖、回不回收）[^src-transcript-sanwen]——用错误示范做钩子。
4. **清单可执行**：三招=看印记（AU999）、看证书（CMA 质量认证）、看平台资质[^src-transcript-sanzhao]，每招一个可照做的动作。
5. **跨博主同构**：老许《用这几个方法买珠宝，你还会被坑？》沿用同一"方法清单式"选题，聚合于老许 topics《行情价格与选购话术》[^src-bili-laoxu-jifa]。

## 步骤 / 动作（可照做）

1. 选一个观众最易踩坑的知识点。
2. 压缩成 2-4 步清单，标题写成"N 招 / N 问 / N 种"。
3. 能押韵的价格/分级梯度编成口诀，且像郭颖那样自评边界（"商业上的常规说法，不见得一一对号"），不夸大[^src-transcript-wanggou]。
4. 开头先演一个"不懂行的问法"或"翻车现场"，再给正确版本。

## 边界与反例

- 口诀是"商业常规口径"不是鉴定结论，必须自评边界[^src-transcript-wanggou]，否则误导消费者按口诀砍价。
- 数量凑不齐时硬编"五招"会注水；2-3 招讲透优于 5 招凑数。
