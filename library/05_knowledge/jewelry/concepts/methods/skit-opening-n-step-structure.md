# 情景剧开场+N步清单口播结构

> **【draft · 待核】** 一句话定义：口播不直接讲知识点，先演一段现场情景剧（粉丝拿来宝问真假）或做一次考试互动，再把结论收拢成 N 步清单——开场留人，清单留料。

## 模式（原则）

1. **情景剧开场**：《三招鉴别假黄金》开头演"发财了发财了赚大发金镯子——这你也敢确定是黄金？"的现场对话，自然引出"假黄金怎么辨别"[^src-transcript-sanzhao]。
2. **考试式互动**：《一招判断和田玉优劣》拿两只手镯让观众（也是学珠宝的博士研究生）猜哪只贵，讲完结构松紧判断后一句"考试结束拿回去吧"[^src-transcript-yizhao]——把观众变成被考核对象。
3. **悬念提问标题**：老许《你买的珠宝到底成本是多少？是如何定价的？》以提问式悬念开场（该 B 站片 3.5 万播放、68 评论）[^src-bili-laoxu-price]。
4. **开场后收拢清单**：情景剧/考试只是钩子，30 秒内必须转入可照做的 N 步清单（三招：印记/证书/平台）[^src-transcript-sanzhao]。

## 步骤 / 动作（可照做）

1. 找一个真实粉丝提问/翻车现场做开场脚本（"郭老师，您看这个……"）。
2. 前 15-30 秒只演不结论，制造"这是真是假"的悬念。
3. 随即转入 2-4 步清单，每步一个可照做动作。
4. 结尾可用"考试结束"式互动收束，留评论区答题空间。

- 情景剧过长（超过 30 秒）会喧宾夺主、干货被挤掉；它是钩子不是正片。
- 考试式互动要求博主真有裁判功底，否则变成故弄玄虚。
