# 什么是翡翠的种？

> 来源：抖音@珠宝学者郭颖 | 时长66秒 | 331字转写 + OCR识别画面文字

## 核心概念
翡翠的"种"和"水"是两个不同概念：
- **种**：翡翠内部的质地，也就是硬玉矿物小颗粒的大小、边界形状、颗粒间结合的紧密程度
- 质地越好，视觉效果越好

## 翡翠种的等级（粒径越小种越老）

| 种的等级 | 硬玉颗粒粒径 | 特征 |
|---|---|---|
| 白地青种 | 2mm以上 | 肉眼可见颗粒，最粗 |
| 糯种 | 2mm-1mm | |
| 糯冰种 | 0.5mm-1mm | |
| 冰种 | 0.1mm-0.5mm | |
| 玻璃种 | 肉眼几乎看不到颗粒 | 最细 |

## 价值差异
同样雕成两片树叶的翡翠，颗粒粗的白地青和玻璃种相比，价值可以相差上百倍，甚至数百倍。
