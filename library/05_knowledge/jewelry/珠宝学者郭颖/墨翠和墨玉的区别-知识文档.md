# 墨翠和墨玉的区别

> 来源：抖音@珠宝学者郭颖 | 约476字转写 + 画面OCR

## 核心概念
- **墨翠**：黑色翡翠，表面漆黑如墨，但用透射光打**透光呈绿色**
- **墨玉**：黑色和田玉（专业称"墨玉"），**不透光**，成因含细小的石墨鳞片状物质

## 墨翠的评价标准（四点）

| 指标 | 要求 |
|---|---|
| 颜色 | 表面越黑越好 |
| 透射光 | 强透光打出来的颜色越绿越好 |
| 反差 | 表面反射光与透射光下绿色的反差越强越好 |
| 结构 | 细腻到肉眼看不出来任何毛病 |

四项都满足 = 质量最好。

## 鉴别方法（一句话）
- **强光打透光**：有透光效应且泛绿 = 墨翠；完全无透光斑 = 墨玉（石墨鳞片不透光）
- 差的墨翠也可能不透光，需结合透射光颜色综合判断
