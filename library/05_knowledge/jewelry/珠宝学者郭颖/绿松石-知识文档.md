## 一、名字的由来：为什么不叫"蓝松石"

- 中国最早只叫"**松石**"，不带"绿"字；相传其"形似松球、色近松绿"（口播作"行进松球色进松绿"〔转写〕），说的是松枝颜色、松球形状，故与松树挂钩、本就是绿色。
- 清代中期**乾隆的母亲特别喜欢松石里的绿色**，才在"松石"前加一个"绿"字，成了"绿松石"。
- 西方称绿松石为"**土耳其玉**"，认知主流来自**古波斯（今伊朗）与美国**矿区，产出的颜色偏蓝；清代中后期美国开矿后，蓝色审美随国际化进入中国，后来市场上甚至形成了"**高瓷、高蓝、绿铁线**"七字诀作为常规质量评价标准。
- 〔观点〕现在行业也在**回归中华文化本源**，越来越多同行重新偏爱标准的绿色松石。

> 简言之：中国赛道看绿，美国/伊朗（古波斯）赛道看蓝。

## 二、颜色不止绿色：三大类与各色名

绿松石颜色因所含**不同矿物质**而变化，大致分**蓝、绿、黄三大类**，严格按色卡细分绿色就有十几种以上：

| 色系 | 代表色名 / 产地特征 |
|---|---|
| **蓝色** | 洞子沟"水润蓝"、云盖寺"暴力蓝"〔转写〕、秦谷"天空蓝"；当前国内最受欢迎 |
| **绿色** | 著名产地**鸭脚山**草绿色、近年流行的"菜籽绿" |
| **黄色** | 菜籽黄（中国有产）；颜色饱满度高的黄色品类也不少 |
| **其他（非主流）** | 红色（去年曾掀起热潮）、紫色、黑色、金黄色，以及较暗的**棕色调（行内称"巧克力色"）** |

> 不同颜色对应不同矿区的产地特征；非主流颜色还要注意其他矿物含量，**科学鉴定必不可少**。

## 三、怎么挑：三条标准

| 维度 | 要求 |
|---|---|
| 颜色 | 第一最好**纯色**；第二**饱和度高** |
| 质地 | **瓷度高、硬松**（瓷地硬松），品相才 OK |
| 铁线 | 追求"高瓷高蓝无铁线"为佳 |

## 四、实战看货（潘家园淘绿松大珠）

- 买家要一颗绿松大珠子穿手串或配项链。
- 好货标准：**通体看是浑圆均匀的蓝色**；仔细看表面有**清晰细小纹理（类似开片纹路）**，特别耐看——不是"微观均匀无色差"，而是这种带细微纹理的最有味道。
- **自然光下比灯光下更好看**；颜色偏蓝在全球都受欢迎。
- 现场一颗细腻、瓷度可以、未盘玩的蓝松大珠，砍价后约 **3000 元**成交〔转写，摊主成本 3200〕；未盘过的料子会随盘玩慢慢变深变浓。
