## 一、这是什么

把郭颖抖音账号的珠宝教学视频，系统性地**下载 → 本地语音转写 → 按品类归并成结构化知识文档**，形成一套可检索、可复用、可引用的珠宝知识底座，支撑 AI 模特图、短视频脚本、自动化运营与日常鉴藏。

- 账号台账共 **387 条**视频；已下载转写 **192 条**，归并为 **17 份综合《知识文档》**。
- 转写用本地 FunASR（SenseVoiceSmall + fsmn-vad）离线完成，**零 API 费用、零失败**。
- 全部知识文档已入 git；视频与台账表格按仓库存储分工**本地持有、不入 git**。

## 四、怎么用

- **想系统了解某品类**（如珍珠怎么分级）→ 直接读 A 类对应《知识文档》。
- **想学地摊淘货/砍价/估价** → 读 B 类三份潘家园手册。
- **要引用某句原话/核对出处** → 按台账 `local_path` 或 `transcripts/{视频名}/` 找原始转写。
- **想知道某条视频采没采、讲了啥** → 查 xlsx 台账（含 value_level、downloaded、transcribed、review_* 列）。
- **想扩充知识库** → 先看《普通展示187条筛查报告.md》的 A 类补采清单。

## 五、可信度标注约定（阅读时务必注意）

文档对信息强度做了显式区分，引用时不要混用：

- **〔转写〕**：来自语音自动转写的数字/专名，可能因口误或识别错误存疑，正式使用前回看原片核对。
- **〔观点〕**：博主主观看法或文化输出，不是客观结论。
- **待补**：口播未展开、暂缺可靠来源的内容，未硬填。
- 无标注的体系性内容（如 GIA D–Z 分级、摩氏硬度、FunASR 明确转写的事实）可信度较高。
