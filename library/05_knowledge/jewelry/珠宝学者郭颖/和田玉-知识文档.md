## 一、和田玉是什么

- **地位**：和田玉是"**中国的玉石之王**"，档次很高，是东方玉文化的代表。〔观点〕博主长期呼吁建立中国自主珠宝知识体系、推动和田玉等东方文化对外输出。
- **成分与硬度**：按国标（GB/T 16552 珠宝玉石名称），以透闪石为主、达到玉石级的玉石统称"和田玉"，**并不按产地命名**——即新疆料、青海料、俄罗斯料等只要成分达标，都可定名为和田玉。摩氏硬度约 6–6.5，具韧性、质地致密。
- **结构与观感**：典型为**纤维交织结构**；优质料肉眼近乎"无结构"，细腻均匀、表面呈**油脂光泽**（油脂状反光），行话概括为"**温润**""**润、白**"。
- **行业特点**：和田玉分产地、料不一样价格也不一样（见第二节）；它不像钻石那样有全球统一透明的计价体系，价格更多凭"料、工、形、皮"综合判断。

## 二、产地料：新疆料、青海料、俄罗斯料

行业内和田玉按产地主要分三大料，**料不同、价格不同**。口播预告"新疆料、青海料、俄料区别在哪、价差多少"的直播专场未在本批视频展开，差异细节**待补**；已口播要点整理如下：

| 产地料 | 口播中体现的特征 | 提示 |
|---|---|---|
| **新疆料** | 质地**致密、坚韧**，油润度好；"老的新疆和田料叫碧绿如翠〔转写〕" | 行内心中的"正统"，价格高 |
| **青海料** | **水**、偏透；常见明显**水线**（一条较透明的白色线状纹）；质地相对**疏松**，细腻坚韧程度不如新疆料 | 见水线常先往青海料想；"青海料太水了"是老板原话 |
| **俄罗斯料（俄料）** | 油润度在俄料里尚可；碧玉俄料颜色更鲜艳、但常见黑色小点（鉴定特征） | 俄料碧玉推动了碧玉颜色"向翡翠方向走" |

- **水线**：打光后屁股上一条明显的小白纹，青海料常见；俄料也可有〔转写中老板区分"是俄料、不是青海料"〕。水线本身不是假货，但会影响料的致密观感。
- **质地对比实例**（8880 元三件套开箱）：大牌亮抛、水线明显、质地偏松；中牌乌抛、质地细腻（"像熬干了水的粥，但还没熬干锅"）；小牌质地最细、无水印、有天然结构纹理。博主结论：**料疏松的工反而上不去**，块头最大的大牌档次未必最高；同样预算下零售买到这种水平"不算贵"。

## 三、山料与籽料

- **山料**：山上开采出来的原生矿石。
- **籽料**：原生矿经风化崩落、被河流**搬运几十上百公里**冲入河床，翻滚磨圆后的**次生料**。
- **籽料的典型特征**：外形**浑圆化**；表面留下天然**毛孔**（小麻坑）；质地疏松处（行话"浆"）被磨掉、原小裂隙在翻滚磕碰中崩落，形成自然凹槽。
- **玩料**：籽料里最珍贵的是"**玩料**"——不用上雕工、直接上手把玩的籽料。其价值点：
  1. **形状**适合把玩，不歪七扭八，料型规整（籽料里形状完美很难得）；
  2. **没有明显大裂**（行话"十籽九裂"，好料的裂不明显且已"长合"）；
  3. **皮色**好（如洒金皮）；
  4. **润度**非常好，一眼看上去温润。
- **山料 vs 籽料价差**：行内公认籽料远贵于山料；同料做串，籽料比山料光泽更强、颗粒更细、颜色显得更黑。**具体价差倍数口播未给数字，待补**。
- **料头判断**：如何区分"籽料"与"大料切下的小料头"——籽料**多面（底面、侧面、正反）都有皮、皮包绕面积大**；料头只在一两面见皮、皮呈单一弧度包下去。

## 四、籽料真假鉴别（真皮真籽 vs 假籽）

> 要点：**必须形状、皮子、毛孔、皮色综合看，不能只看单一指标。**

| 鉴别点 | 真皮真籽 | 假籽（山料仿制 / 染色） |
|---|---|---|
| **外形** | 自然浑圆；即便有平面也在常年磕碰中磨圆，无明显切痕 | 要么"完美过头"不自然；要么有明显**刀口/切割痕迹** |
| **表面** | 自然毛孔、小麻坑、凹槽（疏松处磨蚀） | 毛孔不自然 |
| **皮色** | 颜色有深有浅、**有自然过渡**；致密处颜色浅、表面风化疏松处显得深，深浅交错 | 染色皮**过于浓艳单一、无过渡**；颜色在裂隙处**集中沉积得特别深** |
| **僵** | 玉与僵（石）共生，行内反以"有无相生、难易相成"留僵证明天然、形成优劣对比 | — |

- **僵（"姜"）**：与玉共生的石性部分，质地边较差；老玉雕往往直接剜掉，如今为证明籽料身份常刻意保留，形成好料与僵石的对比。

## 五、皮色、沁色与黄沁

- **洒金皮**：皮色呈洒金状、飘洒小金点，金黄底色；好皮是籽料加分项。
- **秋梨皮**：经典皮色，色如秋梨，比一般秋梨皮更亮者为佳；带红黑皮者有"沧桑感"，象征在河床中沉淀打磨时间久远。
- **沁 vs 沁色（埋藏蚀色）**：
  - 真正由**埋藏后受矿物质腐蚀**形成的沁色，质量差；
  - 好的"沁"（如黄沁）是**赤橙色、三价铁"吃"进去，里外都有颜色**，在石头形成过程中即带入，并非后期埋地蚀出，质量高。
- **黄沁料**：天然成分本不白，由内部铁离子自然长成颜色，不是后期染色。
- **一次皮色（风化外皮）**：料出露地表后表面氧化、风化形成的颜色。
- **独籽/独雕**：保留原石原生态形状雕刻（如财弥把件），浑圆立体、手握舒适、"推出油"的润感更佳。

## 六、颜色品种体系

和田玉按颜色可分出多个商业品种，彼此多为过渡关系：

| 品种 | 特征 |
|---|---|
| **白玉** | 白色主体，油性好、油脂光泽强；市场销量最好 |
| **青白玉 / 青玉** | 青白至青色调 |
| **青花料** | **介于白玉与墨玉之间的过渡品种**：白处是白玉，墨重处近墨玉；"有点墨又不够墨、有点白又不够白"。黑白相间有**水墨山水**感，牌子雕刻仿中国山水画**皴法**（背面打光、正面皴出山水、大面积留白），艺术性强。约 2014–2015 年翡翠、白玉价格高企、百姓追不动时，青花料凭"出身好（玉石之王）、有味道、价格不贵"迅速走红〔转写〕 |
| **墨玉** | 黑色和田玉（**不是**碧玉、**不是**墨翠）；黑色来自细小**石墨鳞片**，**完全不透光**——再强的光打进去也是黑的 |
| **碧玉** | 暗绿至鲜艳绿色品种（见第八节） |
| **翠青（玉带翠）** | 白玉底子上带淡淡青绿色（见第九节） |
| **烟紫 / 藕粉 / 三色** | 青海料特色彩色品种（见第十节） |
| **糖玉** | 和田玉著名小品种，价格不算特别高但受欢迎；常做老型珠、九颗一串（"九九归一/长长久久"之意） |
| **黄沁** | 见第五节 |

> 注：民间习惯"凡带青绿色都往'翠'上靠"（如历史上的麒麟翠之类），但翠青是和田玉上的翠色带，与翡翠不是一回事。

## 七、黑色玉石鉴别：墨玉 / 黑青 / 塔青 / 黑碧 / 墨翠

"看起来黑"的和田玉与翡翠其实是**不同成因、不同透光性**的一族，务必分清：

| 品种 | 本质 | 颜色观感 | 透光性（强光电筒打） |
|---|---|---|---|
| **墨玉** | 黑色和田玉，黑色为**石墨鳞片**包裹体 | 表面漆黑 | **完全不透光**，再强的光打进去也是黑的 |
| **黑青** | 青玉颜色过浓过暗（本身青绿色） | 表面发黑 | 弱透光，仔细看能透一点青灰 |
| **塔青** | 青玉上品，表面泛青、没那么黑 | 泛青绿色，色偏灰、不及碧玉鲜艳 | **比黑青更透光**，青灰色调 |
| **黑碧（黑绿）** | 碧玉颜色再加深变黑 | 黑绿 | 青玉系透光逻辑 |
| **墨翠** | **黑色翡翠**（不是和田玉） | 表面漆黑如墨 | 优质者透射光下**满绿**；差的墨翠也不透光 |

- 规律：表面越黑越要加"黑"字（黑青、黑碧）；表面泛一点青绿色才叫"**塔青**"。塔青产地为新疆塔什库尔干（塔县）一带（行业常识；视频口播未展开具体地名，待补）。
- **墨翠详见《翡翠-知识文档》**：墨翠（黑色翡翠）的完整评价四点（表面越黑越好、透射越绿越好、反射墨色与透射绿色反差越强越好、结构细腻无肉眼瑕疵）已在该文档展开，此处不重复。本视频仅强调其与墨玉的分界：**墨玉=石墨鳞片、完全不透光；墨翠=翡翠（色致暗）、优质者透满绿**。

## 八、碧玉与碧玉猫眼

### 碧玉手镯挑选要点
- **看货光线**：不能在搭大棚、光线杂的地下看；要到**阳光下——北方晴空上午 10 点、非阳光直射**效果最好。
- **颜色**：要**均匀**、通体碧绿色；现代俄料碧玉从铁离子暗绿走向铬离子鲜艳绿（"向翡翠方向发展"），颜色比老坑更亮。
- **净度**：不要有太明显的白色棉絮一块一块。
- **黑点**：俄料碧玉常见黑色小点（**鉴定特征**），越少越好、最好没有；但博主个人认为有一两个也挺好——是"身份特征"，不是坏事〔观点〕。
- **质地**：颗粒越细越均匀越好，顶级近"和田玉无结构"；粗颗粒与细腻料价格可差约 **3.5 倍**〔转写〕。
- **镯型**：圆条（福镯）废料、上手沉；扁口（平安镯）省料、较轻；圈口按佩戴人选（如 53–54 圈口）。

### 碧玉猫眼
- 和田玉为纤维交织结构，**只要切磨方向对，出猫眼并不难**。
- **早年是"废料"**：行内早期把猫眼料做成大蛋面、赶两个大平面中间起棱，硬把眼线（光带）赶上去，效果很差；博主自嘲当年"被忽悠"〔观点〕。
- **好猫眼标准**：眼线"**活**"——强光下晃动珠子，眼线在珠面上**左右游走、有开合浮动**；猫眼是**动态**特殊光学效应，纹丝不动的叫"死鱼眼"。
- 单晶宝石猫眼可做到眼线上下开合；集合体玉石（和田玉）能做到左右晃动眼线游走即属最高评价。
- 如今一条整串、眼线灵动、质地细腻的碧玉猫眼特征鲜明、独一无二，评价很高（视频标题称十几万级，**具体价格待补**）。

## 九、"翠"字辈：翠青 vs 天山翠（差价可达 10 倍）

| 对比项 | **翠青（和田玉）** | **天山翠（石英质玉 / 石英岩）** |
|---|---|---|
| 本质 | 和田玉（白玉底上飘翠色带） | **石英岩**，不是和田玉 |
| 光泽 | 温润细腻、油脂光泽 | 油脂光泽强、**透明度很高**，一眼可与和田玉区分 |
| 致色 | "翠"=三价铬离子，"青"=二价亚铁离子〔转写〕 | — |
| 翠色评价 | 翠色要**明艳**：明=亮度高，艳=色浓度高；**往绿上走**则贵，**往青（发闷发暗）上走**则便宜 | 色带颜色与分布规律"很像"翠青，但材质不同 |
| 价格 | 公斤级、翠色鲜亮、巧色雕件（如持莲观音巧色绿莲台）价高 | 平价装饰小牌（四六牌、倒棱倒角，写意山水感） |

- 同是带翠，翠色发闷发青 vs 鲜亮明快，差价可达约 **10 倍**（视频标题）。
- 天山翠牌子：长方形四六牌、四边四角倒圆，"方中带圆、圆中带方"，青绿色有写意山水意境；虽为石英岩但质地细腻、肉眼几无颗粒感，适合做伴手礼。

## 十、多色玉："黄金万两不如玉有三色"

- 口播以一块**青海三色料**为例：上面**烟紫色**（有天）、下面**烟紫色**（有地）、中间白玉+一点**翠青**和**藕粉色**——"天地人三台"，上下有紫把中间白色包住，契合中国传统"有天有地中间有人"的文化意象。
- **评价要点**：颜色分明清晰；中间白处干净无尘无染；紫色要**胭紫（烟紫）**而非泛黑发灰的紫，浓淡相宜、有明亮度；带一定透明度。
- 雕件上巧色（把绿色飘带雕成小凤鸟）可顺色就形。
- 〔观点〕"玉有三色"之所以受追捧，在于天然多色难遇、且契合传统文化；但并非颜色越多越无脑好——仍要看每一色的正、净、润。

## 十一、雕工题材与文化寓意

> 总纲：玉石雕刻"**图必有意，意必吉祥**"。

| 题材 | 寓意 / 出处 |
|---|---|
| **金鱼**（耳饰，两条游鱼） | "**金玉满堂**"——语出《道德经》"金玉满堂，莫之能守……功遂身退，天之道"，劝人知止、勿贪；民间又解为小两口**相濡以沫、互相扶持**（耳饰一边一个，各自独立、合则成双） |
| **大树叶** | "**大业有成**"（叶=业；常加小虫谐音"成"） |
| **貔貅（皮丘）** | 皮为公、丘为母，一公一母；**独角=明辨是非**（典出地藏菩萨坐骑谛听辨真假美猴王），独角只能一不能二、不可模棱两可；雕角要**刚直有力**，雕成软弯属"少女儿童版"，寓意力度不足 |
| **财神 + 弥勒（"财弥CP"）** | 财神属"五福神"：**福、禄、寿、喜、财**五位各掌一事；弥勒大肚能容；两者凑一起讨喜 |
| **牡丹 + 燕子/莲花** | 牡丹=花开富贵、国色天香；莲花下有藕=**多子多福** |
| **葫芦** | 谐音"**福禄**" |
| **并蒂莲** | 花开并蒂，象征夫妻爱情（"在天愿作比翼鸟"类意象），不宜作"第三人"题材 |
| **兽形料（龟、鹰）** | 料型若像龟，龟在传统文化中"四海龙宫一人之下"、象征阴阳和谐、长寿 |

- **雕工鉴赏**：如持莲观音的"杏仁眼"——把眼周一刀铲平、淡抛光，远看双目微合却眼神提亮，"闭目静思、心中笃定而不喜形于色"；嘴唇似笑非笑、有怜悯之情，为高雕工。
- **玉雕线条**：细工走线可追溯到周代"勾连纹"类玩法；工不复杂，但能衬出质地细腻与油润光泽。
- **错金银（金银错）**：中国传统玉作技艺——在玉面开"口小腹大"的细槽，利用金的延展韧性嵌入擀平，时间久了与玉融为一体，金丝实为嵌槽而成。

## 十二、选购、看货与砍价

- **看货光线**：晴天上午、避开大棚杂光与强光直射，以自然光评色。
- **老方法**："**远观其势，近取其质**"——远看整体气势（珠形饱满圆浑、接近球形为上，扁者次之），近看质地有无明显大毛病。
- **砍价文化**〔观点〕：行内砍价不是生死对峙，而是高兴聊天、实话实说沟通，双方都体面；可从雕工、小瑕疵切入让价。
- **开箱实例**：网购"买二赠一"和田玉牌子，先看水线判产地、再看细腻度与抛工（亮抛显光泽、乌抛（柔光）藏瑕），最后估"料+工"综合值不值。

## 十三、市场行情与观点

- **行情波动**：青花料在 2014–2015 年行业最热时"还不卖钱"，后因翡翠、白玉价高、百姓转向而走红；碧玉猫眼十年前是"废料"，如今身价大涨——说明小众品种审美与价格会随市场轮动。
- 〔观点〕博主把珠宝视为"装饰生活、美化生活"之物：看着开心、心情愉悦即带来正能量；比较中见幸福（"100 条串里独一无二"的猫眼串最讨喜）。
