# 郭颖视频近重复普查报告（转写文本 + 视频画面 双维度）

> 普查日期：2026-10-12　范围：郭颖库全部 238 条作品（238 个 mp4、238 份转写）
> 方法：本地实测（md5 + 字符 bigram TF-IDF 文本相似度 + 16x16 dHash 画面感知哈希 + 高相似对抽帧肉眼复核）
> 工具：`scripts/transcript_dup_scan.py`、`scripts/video_visual_dup_scan.py`（纯标准库/仅依赖 ffmpeg，可复跑）
> 结论可信度：已查证（脚本实测 + 高相似对逐字通读、逐帧肉眼核验）

## 一、为什么做两道查重

T-38「郭颖 A 类 46 条补采」收官后做全量 md5，发现 1 对二进制完全相同的视频。单一手段各有盲区，因此补两道：

- **md5**：只能发现"文件完全相同"（一稿两发、下载串流）。
- **文本相似度**：发现"口播雷同"——同段重讲、长短剪辑、片段切片（哪怕画面是重拍的）。
- **画面感知哈希**：发现"画面相同"——同一视频文件/同片剪辑（哪怕讲稿被重新配过）；并能反过来区分文本同源的两条到底是"同片剪辑"还是"同稿重拍"。

文本与画面互补，覆盖"讲稿相同但重拍""画面相同但改稿"两类交叉情形。

## 二、文本转写普查

## 三、视频画面普查

方法：每个 mp4 快速 seek 均匀抽 8 帧，ffmpeg 降采样为灰度小图，纯 Python 算 dHash；两视频间统计"近完全相同帧"（Hamming 距离≤阈值）的数量与占比。

**一次重要校准（已固化进脚本默认值）**：先用 9x8（64bit）粗 dHash，报出 73 对候选，且高度跨主题连通（翡翠分级视频竟与多条钻石视频"相似"）。对占比≥0.75 的 7 对逐帧抽图肉眼核验，确认**全部是同一演播室、同机位、同服装、同桌面布局的"同场连讲系列"，并非同片**：

- 《3D硬金》↔《黄金六不买》：金色背景同场，一条讲工艺、一条讲避坑，字幕/道具不同；
- 《中国民间最受欢迎十人物》↔《白龙马的故事》↔《麒麟纹饰雕刻》：瑞兽文化同场连讲，金佛像群 / 浅绿玉雕 / 深绿麒麟牌各不相同；
- 《钻石和彩宝哪个更保值》↔《黑钻能不能买》、《咖钻是天坑》↔《钻石购买的天坑》、《碎钻》↔《保值》：绿背景钻石系列同场，话题与字卡/插图不同；
- 《和田玉耳饰学问》↔《手链玉石珠宝寓意》：珠串桌同场，耳饰与手链道具特写不同。

改用 **16x16（256bit）细 dHash**（能区分手势/字幕/道具/插图差异）后噪声清零：

- **强判同文件/同片（近同帧占比≥0.8 且最小距离≤13）：仅 1 对——帝王绿（占比 1.00、最小距离 0）**，与 md5、文本三重证据一致。
- 待复核区（占比 0.25–0.8）：仅 1 对（和田耳饰↔手链，占比 0.25、2 帧、距离 10），肉眼确认为同场不同饰品，非重复。
- 其余所有 238 选 2 组合，最小 Hamming 距离均 ≥10 且近同帧 ≤2；9x8 误报的同场对在 16x16 下近同帧归零、最小距离 17–23。
- 文本同源的碎钻/红宝石/坦桑石 3 组，画面近同帧均为 0（坦桑石两版最小距离 23），证明是**独立录制/独立编排，不是同一视频剪辑**。

## 五、口径（三个数字，用途不同）

- **抖音作品：238 条**——238 个真实 vid/URL，对应 238 个 mp4、238 份转写，全部保留。
- **独立视频画面/素材：237 个**——仅帝王绿是同一文件重复；碎钻/红宝石/坦桑石虽是同知识点，但是三次独立拍摄，镜头与表达可互为补充，按独立素材计。
- **独立口播知识点：234 个**——4 组文本同源各去重 1；知识库归并与引用按此口径，一律以表中"主条（完整版）"为准，次条不再单独计知识点。

这 4 组都源于博主源头行为（一稿多发 / 同题重讲 / 长短版），**不是采集串流**：分散在早期高价值 192 阶段；T-38 的 46 条在铁证法下 md5 两两唯一，两道普查均未在 46 条内发现重复。

## 七、复跑方法

```bash
# 文本（口播）近重复
python3 scripts/transcript_dup_scan.py \
  "library/05_knowledge/jewelry/珠宝学者郭颖/transcripts" \
  --xlsx "library/05_knowledge/jewelry/珠宝学者郭颖/郭颖珠宝视频知识库_总清单.xlsx" \
  --threshold 0.40 --json /tmp/dup_pairs.json

# 画面近重复（默认 16x16/256bit，强判据已内置）
python3 scripts/video_visual_dup_scan.py \
  "library/01_video/jewelry/珠宝学者郭颖" \
  --xlsx "library/05_knowledge/jewelry/珠宝学者郭颖/郭颖珠宝视频知识库_总清单.xlsx" \
  --json /tmp/vdup.json
```

判读纪律：画面脚本"强判"区（占比≥0.8 且最小距离≤阈值）可直接判同文件/同片；"待复核"区（0.25–0.8）**必须抽帧肉眼看**，固定演播室连讲语料里这一区间绝大多数是同场不同内容。新增视频后两道各跑一次即可。

## 八、局限

- 文本抓口播雷同、画面抓逐帧相同；"同款主体不同角度/不同运镜的翻拍"两者都不判为重复（有意为之，避免误报，且这类本就是独立素材）。
- 均匀抽 8 帧，仅几秒雷同的极短片段可能漏检；需要时提高 `--frames`。
- 本库以固定场景口播为主，画面维度的额外重复仅帝王绿 1 例；若未来入库大量外景/展示型视频，画面普查价值会上升。
