# 郭颖视频转写近重复普查报告

> 普查日期：2026-10-12　范围：`transcripts/` 全部 238 份转写　方法：本地实测（字符 bigram TF-IDF 余弦 + Jaccard）
> 工具：`scripts/transcript_dup_scan.py`（纯 Python 标准库，可复跑）　结论可信度：已查证（脚本实测 + 高相似对逐字人工通读）

## 一、为什么做

T-38「郭颖 A 类 46 条补采」收官后做全量 md5 比对，发现 1 对二进制完全相同的视频（帝王绿，博主一稿两发）。md5 只能发现"完全相同"，发现不了"同一段口播被掐头去尾、截取片段、重新剪辑后再发"的轻度重复，因此对全部转写文本做一次近重复（near-duplicate）普查。

## 二、方法

1. 取每份 `transcript.md` 的口播正文：剔除 `# 标题`、`## 第N段`、`> 元信息` 行，再去掉标点/空白/符号，仅保留中文与字母数字。
2. 对正文切字符 **bigram**，计算 **TF-IDF 余弦相似度**（sublinear tf）与 **bigram 集合 Jaccard**；238 份两两比较（约 2.8 万对）。
3. 输出余弦 ≥0.40 的对，对余弦 ≥0.60 的疑似同源对**逐字通读正文人工判定**，区分"同素材重复"与"同系列各讲一款的不同内容"。

复跑：

```bash
python3 scripts/transcript_dup_scan.py \
  "library/05_knowledge/jewelry/珠宝学者郭颖/transcripts" \
  --xlsx "library/05_knowledge/jewelry/珠宝学者郭颖/郭颖珠宝视频知识库_总清单.xlsx" \
  --threshold 0.40 --json /tmp/dup_pairs.json
```

## 三、总体结果

- 扫描 **238** 份；余弦 ≥0.40 的仅 **4 对**；其中 0.40–0.45 为 **0** 对、0.45–0.60 为 **0** 对。
- 全库没有大量"主题相近"的灰区：不同主题、乃至同主题但讲法不同的视频，相似度都低于 0.40，方法没有误伤。
- 4 对经逐字通读，**全部判定为"同素材重复"**（同段口播重发 / 长短剪辑 / 片段切片），无一是"同系列各讲一款"的独立内容。

## 五、口径

- **作品口径：238 条**（238 个真实抖音 vid/作品 URL、238 个 mp4、238 份转写）。
- **唯一独立内容口径：234 条**（上表 4 组各去重 1 条）。
- 这 4 组都是**博主源头的一稿多发 / 长短版 / 片段切片，不是采集串流**：它们分散在早期高价值 192 阶段（10 月 8–9 日铁证法建立前后）；T-38 的 46 条在铁证法下 md5 两两唯一，本次普查也未在 46 条内发现新重复。

## 六、处置

- **视频 mp4 与转写全部保留**：每条对应一个真实存在的作品 URL，保留以完整溯源，不删除任何原始文件。
- **本地台账** `郭颖珠宝视频知识库_总清单.xlsx` 的 O 列 `review_note` 已对上述 8 行标注主/次与同源关系（xlsx 为本地文件、不入 git）。
- **知识文档无需改动**：8 条中只有信息最全的坦桑石完整版（行90）被《彩色宝石-贵重宝石》《彩色宝石-常见宝石与平替》挂为来源，其余 7 条均未按 vid 引用；品类文档是综合去重编写，不存在重复链接或知识点重复计数。
- **后续引用原则**：使用这 4 组素材时一律以表中"主条（完整版）"为准，次条不再单独计知识点。

## 七、局限

- 文本相似度只能发现"口播文本雷同"；发现不了"画面相同但讲稿完全重写""纯视觉/镜头重复"。后者需对抽帧做感知哈希（pHash）普查，对当前以口播知识为主的语料收益较低，暂不实施。
- 阈值 0.40 以下不排除弱相关；本次已对全部 ≥0.40 的 4 对完成人工通读。新增视频后按第二节命令复跑、对 ≥0.60 的新对人工研判即可。
