## 执行纪律（每批重复，硬性）

### 下载与防风控（照 multiplatform-media-fetch 铁证法）
- 工具：`mac_computer_use_tool` plane=bu；currentSrc 轮询到 `__vid=<vid>` 锚定身份 → 同 objectid 取最高 `br`；高码率 `bu.download` 30s 易超时 → 直链写 `/tmp/dy_url.txt`，cell 外 curl（带 Referer/UA）立即落盘，签名链不复用。
- **一条视频一个独立浏览器 cell**；逐条串行；条间 ≥32s、页面停留 10–20s 模拟真人；单会话 ≤15 条；当天第 1 批按天记，跨天自动重置。
- 撞验证码 / 登录墙：立即停，`interaction.request_action(type=browserControl)` 交用户，不硬刚。
- 落盘：`library/01_video/jewelry/珠宝学者郭颖/`。
- **每下完一条立即**：md5 与本批已下文件两两比对（重复即串流，删错重下）；ffprobe 验视频流+音频流；工单本表状态 ⬜→✅。中断后续跑只找 ⬜，不重复下载。

### 转写（FunASR）

- 同音错字结合画面校正；口播未展开/数字待核按既有规范标〔转写〕/「待补」。

### 双轨分析（画面层 + 音频层缺一不可，照 video-effect-analysis）
- **画面层**：ffmpeg 抽帧 + dHash 去重 + Read 逐帧；拆 HOOK/SETUP/PEAK/CTA 与情绪弧线；**先答导演动机**再记工具；镜头语言表（景别/运镜/转场/光线/色彩质感/主体）；抽象词翻物理词；产出豆包系（Seedance / 即梦）与可灵可复用提示词，改写至「足金O字链嵌蓝宝石」。
- **音频层（五问）**：音频构成占比 / 文案规律（摘录原句）/ 音乐参数（BPM·调性·乐器·情绪）/ 音画配合逻辑 / 事件触发拟音机制；产出可复用音频配方。
- **分型检查**：按视频目标分型（产品展示/模特佩戴/教学/故事氛围/知识讲货）选检查维度，不套统一模板；每条卡片注明分型。
