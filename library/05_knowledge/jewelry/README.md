### 两者怎么配合（不是重复建设）

- **先要体系，后查出处**：写内容/做决策先读郭颖综合文档拿框架；需要原始出处、更多案例或郭颖没覆盖的品类（如大量原创设计、客订开箱）时，下钻老许 VideoNote。
- **交叉验证**：两位都讲的品类（钻石 4C、彩宝产地、鉴定避坑、行情话术）可互相对照，结论一致更可信、有分歧则标注。
- **第二步语义加工的去向**：老许 744 篇原子笔记未来提炼 topics 主题页时，郭颖的综合文档可作为同品类的"成稿参照"，但不得互相照抄、不得抹平来源差异。
