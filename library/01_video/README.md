# 视频资产库（library/01_video）

本目录存放各平台采集的视频**本体**与**资产清单**。

- 视频 / 音频文件体积大，**不进 Git**，仅本机或网盘持有；
- 每个来源的 `manifest.csv` 台账**入库**，是跨设备、跨会话、跨仓库可见的权威资产清单；
- 字段定义、评级标准、维护与对账流程统一见
  [视频资产台账规范（manifest）与价值评级 SOP](../../docs/guides/video-asset-manifest.md)。

## 目录约定

```
library/01_video/<平台或内容大类>/<账号>/
├── *.mp4            # 原始视频：gitignore，不入库
├── manifest.csv     # 该来源全部视频的资产台账：入库（身份/价值/状态/md5/时长/文稿位置）
└── README.md        # 来源说明（可选）
```

## 常用操作

- **改台账**：编辑对应 xlsx（在 `library/05_knowledge/<域>/<账号>/` 下），提交前运行
  `scripts/xlsx_to_manifest.py` 刷新 manifest 并看到「对账通过」，命令见 SOP §6。
- **换设备恢复**：按 manifest 的 `url` 重新下载视频到 `media_relpath`，重跑脚本，
  md5 一致即同一文件。
- **新增来源**：按 SOP §7 建两级目录与 `manifest.csv`，并在本页「来源索引」登记一行。
