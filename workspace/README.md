# 运行时工作区（workspace）

> **文档类型**：Reference（参考资料）
> **更新频率**：工作区结构变更时
> **维护者**：AI自动维护

> 本目录是项目的运行时工作区，存放过程件（日志、临时文件、采集状态等），**不入库**（gitignore）。
> 设计参考高顿CPA项目的`data/_workspace/`，根据本项目特点简化为3个子目录。

---

## 目录结构

```
workspace/
├── logs/          # 运行日志（中期保留，30天）
├── tmp/           # 临时文件（用完即清）
└── capture/       # 采集相关（抓包、URL清单、批次状态，短期保留最近3次）
```

## 各子目录用途

### logs/
- 批量任务的运行日志
- 转写/OCR/下载的进度日志
- 保留策略：30天，超期自动清理

### tmp/
- 下载中的临时文件
- 处理中的中间产物
- 保留策略：用完即清，任务完成后删除

### capture/
- MITM捕获的URL清单（videos.json等）
- 采集批次状态（state.json）
- 采集进度台账（manifest）
- 保留策略：最近3次，超期自动清理

## 使用规范

1. **过程件放这里**：任何运行时产生的临时文件、日志、状态文件都放`workspace/`下，不散落在项目根目录或`/tmp/`
2. **不入库**：本目录在`.gitignore`中，不会被提交到GitHub
3. **清理原则**：任务完成后清理`tmp/`，定期清理`logs/`和`capture/`的过期文件
4. **状态记录**：大任务（>3个视频/文章，或预计>1小时）的执行状态放`workspace/capture/state/`，`TASK_STATUS.md`只更新指针级状态
